# 保存 Play 模式中的 UI 调整

打开 Unity 菜单 `Tools > Darwin Farm > UI > Save Play UI Layout`。

1. 进入 Play，正常打开要调整的 UI。
2. 在 Hierarchy 选中 UI，通过 Inspector 或 Scene 工具调整位置、尺寸、字号、字体、颜色、按钮状态颜色或布局组件参数。
3. 默认在退出 Play 时自动保存检测到的手动修改；也可以点击“保存检测到的 UI 调整”。
4. 返回编辑模式后，已有场景节点会恢复对应调整，按 Ctrl+S 保存场景。运行时生成的节点则在下次生成后恢复样式。

普通编辑模式修改仍直接使用 Ctrl+S。WhiteBox 的桌面和移动端物种信息面板已生成并保存在场景中，`JournalContent` 和 `CompactJournal` 都可以直接排版，初始化不再重设字号和位置。

保存资源是 `Assets/Resources/GameUI/UILayoutOverrides.asset`。场景中已有节点保存后，对应覆盖记录会移除，后续编辑模式修改继续以场景为准；只有运行时才存在的节点保留覆盖记录。

注意：

- 只保存 UI 布局与样式。动态文字、物种头像、显隐、交互状态、按钮事件和游戏进度不会保存。
- 新建或删除控件请在编辑模式完成；此工具保存调整，不会把 Play 模式手工新建的控件转成场景对象。
- 某些第三方 Inspector 没有发送 Undo 修改事件时，选中对应的 UI 对象，使用“保存当前选中 UI 的布局与样式”。这个按钮作用于选中对象上的组件，不自动包含子对象。
- LayoutGroup / ContentSizeFitter 控制的尺寸应在布局组件上调整；脚本每帧控制的位置或动画仍由对应脚本负责。
- 运行时节点通过场景及完整层级路径匹配。改名或移动生成路径后，需要重新保存该节点的调整。
- 字体引用需要是项目资源。临时生成的材质或字体实例不适合跨次运行保存。

关闭“退出 Play 时自动保存”即可恢复普通的临时调试方式。保存资源中可以逐项移除不需要的覆盖。
