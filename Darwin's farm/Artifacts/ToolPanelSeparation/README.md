# 工具面板分离与羊皮纸背景替换

移动端环境工具已从信息抽屉中移出，使用独立的 `EnvironmentToolDrawer`。工具窗口不包含环境／生物信息页签；地块和种群信息仍通过原来的查看入口打开。

PC 和移动端的工具展开面板共用提供的羊皮纸背景。原图复制到 `Assets/Resources/GameUI/EnvironmentToolPanel.png`，像素内容未修改；通过独立 Sprite 的矩形和九宫格边框去掉外围透明留白，并适配不同面板尺寸。

## 已验证

- 工具控件不再属于信息抽屉层级，工具打开时不显示信息页签。
- 工具模式下点击地块只更新操作目标，不打开地块信息窗口。
- 档位选择、投放、撤销和独立关闭按钮使用现有共享工具逻辑，实际操作通过。
- 退出工具后，地块信息和实际种群信息均可正常打开。
- PC／移动端切换后，两端引用同一张背景 Sprite。
- 模拟较小安全区域时工具面板高度为 328 Canvas 单位，内容可滚动；连续刷新 30 次后滚动位置保持不变。
- 原有信息窗口手势回归通过：动画打断、鼠标／触摸所有权、释放／焦点恢复、安全边界、标题拖动及嵌套滚动。
- 运行中只有一个 EventSystem，最终验证无编译或运行错误。

变更已保存到 `Assets/Scenes/WhiteBox.unity`。重新执行现有环境工具安装器时，会维持独立工具窗口和统一背景。验证使用 Unity 6000.2.9f1 Editor 的 PC／移动端展示模式，未执行 Android 真机打包。
