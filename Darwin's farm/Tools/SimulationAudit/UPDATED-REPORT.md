# 生物模拟系统修改与回归报告

日期：2026-10-03。对应修改前发现见 [基线审查](REPORT.md)，逐场景输出见 [results.txt](results.txt)。本次直接编译和调用当前模拟源码；测试程序为 [Program.cs](Program.cs)，使用少量 Unity 基础类型替身和固定随机种子，不覆盖 Unity 场景生命周期。正式项目 C# 构建通过，0 警告、0 错误。

## 这次修改了什么

1. **捕食与能量统一到日尺度。** 每单位猎物体型的基础能量由 1 调到 15，仍乘 0.8 捕食效率；捕食者把整只猎物吃下后多出的能量保留至最多 10 天的能耗。每天最多捕食某猎物种群 10% 的个体，稀少猎物因此有避难空间。捕食者的承载量 `K` 改由猎物的可持续日净生产量估计，不再以整群现存身体能量估计。三个数值是固定常量，未增加测试面板旋钮。
2. **运动能力产生实际觅食收益。** 固定能耗为 `size + movement×0.02`（下限 1）。觅食效率为 `0.75 + movement×0.0025`，作用于植物可接触比例、食草种群竞争权重、捕食所得能量与捕食者间分配。删去了面板里的体型与运动能耗权重，避免旧的高运动成本设置覆盖新平衡。
3. **把环境适应度作为绝对取食限制。** 适应度为 `clamp01(1−(|温差|+|湿差|)/90)`。适应度同时限制实际可取得的食物和长期承载量，而不只是多种群竞争的相对权重。这样轻度变化仍可觅食，温湿度各突变 50 则确实会造成致命失配。数值模拟器的 `K` 预估也同步更新。
4. **修正选择压力的口径。** 当日实际摄食率使用捕食前人口作分母，驱动运动压力；长期资源机会 `K/捕食前人口` 驱动体型压力，不再因捕食先减少人口而凭空产生“能量盈余”。没有可用食物时，不定向选择更高运动能力。食性方向压力仅在当日摄食不足时生效，吃饱的捕食者不再持续向低食性级别演化。
5. **三级上限与边界。** 食性限定为 0、1、2 级；旧资产中更高数值在种群初始化时会被夹到 2。空的种群列表项会在计算前清理。

## 新结果

| 场景 | 修改前 | 修改后 |
| --- | --- | --- |
| 两级链：植物日恢复 1000，食草 50、捕食者 3，关闭变异 | 第 10 天全部灭绝 | 第 2000 天食草与捕食者分别为 **62 与 5**。 |
| 两级链：同配置，开启默认 30 天变异 | 捕食者食性长期向零级漂移，链条会消失 | 50 个随机种子各运行 2000 天，**50/50 两级都存活**。 |
| 三级链：植物日恢复 10000，食草 500、一级捕食者 20、顶级捕食者 2，开启变异 | 原能量量级不足以稳定支撑顶级 | 50 个随机种子各运行 2000 天，**50/50 三级都存活**。三级链需要高生产力；日恢复 2000 的低生产力示例仍可能失去顶级。 |
| 温湿度各增加 10、25、50；第 100 天变化 | 旧实现对近零但非零适应度过于宽容 | 50 个随机种子各运行到第 365 天：**10 → 50/50 存活；25 → 50/50 存活；50 → 0/50 存活**。剧变仍可致灭绝。 |
| 植物竞争：同为 10 只、体型 10，运动能力 0 对 100，总植物仅 100 | 运动只有额外成本 | 低运动者取得 38.46、高运动者取得 61.54；按各自能耗计算，当日摄食满足率约 0.385 对 0.513。 |
| 捕食竞争：各 10 只捕食者，运动 0 对 100，猎物 20 只 | 运动对捕食无收益 | 低运动者取得 54.55、高运动者取得 87.27；摄食满足率约 0.545 对 0.727。猎物只损失 2 只，符合 10% 日捕食上限。 |
| 边界压力：200 组随机生态配置，各运行 365 天 | 未见负人口与资源越界 | 新模型同样 **0 次**负人口、越界性状、非有限资源或植物库存超限；117 组全群落灭绝，主要包括无生产者或环境严重失配的随机配置，不能当作真实生态概率。 |

`Program.cs` 对轻度变化、剧变、两级/三级长周期存活、运动觅食收益和数值界限设置了自动断言。当前全部通过。修改前的单食草承载量约 5；新的固定能耗下约为 9.8，数值量级与日恢复 100 一致。

## 仍需注意

- 三级链依赖足够的植物日恢复量。低生产力地块允许顶级捕食者灭绝；这属于资源约束，而不是程序错误。
- 大型猎物超过捕食者 10 天储能上限的剩余能量目前会损失。加入腐食/尸体库存会改善守恒，但会增加一套状态；本版按系统简明的要求保留该限制。
- 日捕食上限使少于 10 只的单个猎物种群当天不可被捕食。这是简化的避难规则，有利于防止少量捕食者立即清空猎物，但不是精细空间捕食模型。
- 回归针对单地块、默认关闭的迁徙，以及代码层计算。新加入的迁徙路径和 Unity 场景连接需独立验证。不同 Unity 随机数序列可能改变某一条单次轨迹；多种子结果表明当前目标在测试分布中稳定。

## 复现

在项目目录运行 `dotnet run --project Tools/SimulationAudit/MutationAudit.csproj`。程序无外部 NuGet 包，`NuGet.Config` 清空包源。测试使用 .NET 10 SDK；项目本身仍按 Unity 的 C# 工程构建。
