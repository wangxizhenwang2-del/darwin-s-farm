# 建造与种群 UI 调整

- 移动端放置操作区使用新绘制的背景：上框显示地形与状态，下方三个框对应旋转、确认放置、取消预览。按钮保留原回调，并提供半透明按压与不可用反馈。
- 移动端雷达图的五个属性位置、对齐方式与图形布局同步当前 PC 场景中的手动调整，PC 原布局未改动。
- PC 竖向工具栏为 200×500，整体从 Y=-118 下移到 -142。只伸展纸面两侧的留白，保持五个图标为圆形；对应的点击区域和选中反馈同步调整。
- 展开操作面板保留原 510×560 尺寸及内部布局，向右移动至工具栏旁，间距 12。
- 移动端地形栏复用 PC 预制件的深色框、地形颜色预览与名称分区，名称使用浅色保证对比度，继续保留横滑与触屏选择。
- 安全区域较矮时，放置操作区移到左侧操作列右方，必要时地形栏也让开操作列。

场景已保存至 `Assets/Scenes/WhiteBox.unity`，显示模式为 Auto，编辑器已退出 Play 模式。原始 PNG 像素未修改，外部白色区域由已保存的轮廓网格裁掉。

编辑器升级入口：`Tools/Darwin Farm/Update Build UI and Population Attributes`。重复执行不会增加按钮。完整工具皮肤安装入口也会应用此次布局。

验证：Unity 编译及 C# diff 检查通过；五个 PC 工具入口均通过实际 UI 射线点击、功能映射与选中反馈检查；移动端旋转、取消回调通过；五个雷达属性坐标与 PC 一致；重复升级保持 31 个移动端按钮；模拟 1232×664 与 1232×328 Canvas 安全区域时，操作列、放置操作区、地形栏互不重叠。未进行手机真机测试。
