# 环境工具与移动端 UI 改造

工具顺序统一为：温度、海拔、湿度、植物增量、植物存量。沿用现有数值、费用、时间阶段和水陆作用范围，保留已有枚举数值，避免改变序列化含义。

- PC 左侧工具栏使用提供的完整羊皮纸原图，并为五个圆形入口设置对应点击区域。
- 两端共用五组档位图标。单三角对应小档，双三角对应大档；海拔仅显示升一级、降一级。选中档位通过绿色下划线标识，保留原图配色。
- 移动端保留环境工具入口，四个操作按钮依次竖排为环境工具、暂停／继续、定位玩家、建造地块，使用绿色水彩标签背景。
- 移动端生物能、天数、倍数排列于顶部；操作提示使用长条植物边框背景。
- 两端工具窗口左上角使用圆形植物徽章与“×”，点击退出工具操作。
- 工具窗口继续与地块、物种信息窗口独立。

原图存于 `Assets/Resources/GameUI/ToolArt`，不修改原始像素。`ArtworkSilhouette` 根据保存的轮廓绘制 UI 网格，去掉不透明原图外侧的白色区域。工具分类、档位使用同一份 `ToolArtwork.asset`。

场景为 `Assets/Scenes/WhiteBox.unity`。已保存，显示模式为 Auto。可通过 `Tools/Darwin Farm/Apply Environment Tool Artwork` 重新应用布局；重复执行不会添加重复按钮。`ImportArtwork.cs.txt` 是供 Unity eval 使用的原图裁切与轮廓提取记录，常规使用不需要执行。

## 验证

- Unity 编译通过；C# diff 检查通过。
- 两端五类真实按钮回调、每端全部 18 个有效档位、对应图标和两个“×”退出回调通过；暂停／继续及建造模式切换回调通过。
- 现有输入集成检查通过：触屏松手选地块、拖动不误选、工具模式禁止玩家移动、只读预览、投放与扣费、撤销、PC 选择与信息窗口独立。
- 五工具审计通过：陆地与水域的植物存量、日增量分别生效；预览不修改模型和货币；价格与时间阶段保持现有规则；海拔只允许一档变化。
- 1920×1080 与较窄的 1440×1080 编辑器画面检查通过；模拟刘海安全边距和高 328 Canvas 单位的安全区域时，操作按钮列及工具窗口均位于区域内。
- 连续重新安装两次后，移动端按钮数量保持 31 个。
- 验证仅在 Unity 编辑器完成，未进行 Android/iOS 真机测试。
