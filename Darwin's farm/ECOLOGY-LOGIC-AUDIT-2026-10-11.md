# 生命规则逻辑自查（2026-10-11）

> 历史审计记录。此文中的生育负担公式、分化人数和鸡→鹿第 305 天试算已由同日后续的正式规则重写覆盖；当前实现与验证结果见 [新生命规则实现说明](NEW-LIFE-RULES-IMPLEMENTATION-SUMMARY.md)。

## 范围与结论

检查当前 `SimulationController.SimulateDay` 实际执行的陆地日结算、单性状变异、植物与猎物账本、迁徙、原地分化、预设物种转化及模型对外数据。旧策划附件中的 `0.005` 出生系数和每 5 日多项变异已被用户后续要求覆盖；本轮保留默认 `0.1`、每日一次、每次单项步长 `1`。没有改变 JSONL 字段名称或迁徙、转化事件接口。

19:12 报告中的温湿反向演化由“候选降低适应度 → 假设幼体减少 → 群落总需求减少 → 出生抑制松动”造成。这是共用计算口径的问题，不是温湿方向判断的孤立问题。现已改写成年负载、幼体需求、候选评价与资源预测的关系；没有添加“温湿只能向环境变化”的特殊分支。

## 已确认并修正

| 规则环节 | 原问题 | 统一后的口径与验证 |
|---|---|---|
| 出生与植物 | 密度抑制取包含**未被密度抑制的预计幼体**的需求，降低适应度或生育可反过来提高密度倍率；植物又为这些不出生的幼体分配食物 | 已存在成年群体的耗食决定当日出生减速；减速后的预计幼体才计入植物需求与分配。饥饿死亡仍仅结算一次，库存仍只扣真实分配量。 |
| 死亡小数余量 | 多种死亡压力叠加时，累计死亡可超过当天存活人数；全灭后残留的死亡债会误杀后来迁入的个体 | 每日死亡余量上限为结算前存活人数，全灭后不保留死亡债；极端失配加断粮的回归用例覆盖。 |
| 性状选择 | 候选温湿改变全群密度倍率，造成 68/68 下的适温 68→0；捕食者候选只取得捕猎能力上升的收益，下降未扣 | 候选固定其他群体，并按自身成年耗食重算密度压力；温湿不能靠虚减幼体负载得益，体型/运动却承担真实成年成本。捕猎能力的**正负**变化均计入。高密度 68/68 与失配回归通过。 |
| 气候与繁殖代价 | 出生在 K 附近降至零时，温湿适应缺乏选择收益；大体型支的生育强度只有幼体食物成本，冷地路线难以同时到达鹿的体型和生育模板 | 增加可调的气候失配死亡 `0.01` 与高生育生理负担死亡 `0.012`。后者按生育比例平方与幼体/成年体型耗食比计算，大小体型承担不同代价；实际结算与候选评分共用同一公式。 |
| 分化与 K | `K_env` 含随适应度变化的幼体需求，而出生减速又另有口径 | `K_env` 表示可持续资源供养的成年人数：扣除竞争成年耗食，再除以本群单只成年耗食；分化后需求使用与当日一致的出生减速因子。仍须当前种群达到 `0.9 K_env` 并通过吃饱、库存和负载条件。 |
| 迁徙 | 候选目的地适应度越差，预计出生越少，分母中的食物需求越低，吸引力反而可能提高 | 邻地吸引使用迁入成年需求和目的地适应度；有同种居民仍无吸引和自然迁入。 |
| 植食目标转化 | 用库存总量按需求比例粗分，未调用实际植物预算与觅食权重 | 用同一植物分配器分别预测当日可吃预算和日补充；来源剩余人数、目标模板与其他食草者一同入账。 |
| 捕食目标转化 | 多种猎物各自按猎手完整狩猎时间估算，可能重复计算猎手当天的捕猎能力 | 候选猎手按现行 `HuntPreference` 在允许猎物间分配一次狩猎努力。 |
| 猎物可持续补充 | 多名猎手各自把相同猎物净新增全部算作自己可用；猎手在种群列表中先后不同会读取不同日期的猎物历史 | 所有群体出生/死亡结算完毕后统一写猎手的补充满足率；其他猎手的需求在其允许猎物间分配一次，再从共享补充量扣除。L1/L2 共享鸡的回归通过。 |
| 数据一致性与旧代码 | 变异后的 `fitT/fitH` 与当天导出的 `fitness` 相差一日；旧 `EvolveCommunity` 和旧目标收益预测仍留在模型中 | 模型在环境、迁徙、变异、分化、转化后集中刷新当前适应度和环境 K；清除了未调用的旧变异选择器与旧目标收益预测。JSONL 原有 `k` 仍是当日食物分配口径。 |

## 仍需实机与规则决策

1. **完整四次物种出现链未由本轮自动用例证明。**默认参数下的冷地单路线也不能直接转鹿；上述正例需要调参。特别需要测试狸猫、猛鹿、雀狮在共享猎物和迁徙下的长期曲线，以及 15 分钟目标。请从单群鸡按测试清单运行并导出 JSONL。
2. **海陆空旧路径尚未接入日循环。**`ecologicalNichesEnabled` 仍可显示为真，但 `RunNicheConversions` 没有由 `SimulateDay` 调用，水格也不执行陆地食物结算。不能据此认为水/空种群规则已完成；陆地四物种链不依赖该开关。启用它前需要单独确定水/空食物与生命周期规则。
3. **气候失配与生育生理负担是新引入的可调规则。**默认值较温和；要快速走出四物种链须按生境调节，不能只看气候匹配而忽略种群数量、库存和猎物。没有普遍老化规则。
4. **多猎物捕食者的长期性状预测仍是单日潜力近似。**转化门槛已经共享狩猎努力和持续补充，实际捕杀仍由唯一猎物账本结算；大型猎手在鸡、鹿混居时的体型/运动方向需要 Unity 曲线验证。
