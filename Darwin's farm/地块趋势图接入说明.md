# 地块趋势图接入说明

## 效果与数据

WhiteBox 的地块信息窗口现为上方趋势图、下方原详细信息，沿用环境信息背景和已有字体。布局保存在场景中，不需要手动挂组件。当前面板设计尺寸为 790×750；原详细信息字号及横向位置保留。

趋势图只显示当前选中地块。种群数量使用左轴，植物库存使用右轴；植物轴默认自动缩放，图例明确标注。植物线相对种群线的高度不表示二者数量相同。种群按稳定 PopulationId 分别记录，图例显示名称和 ID 前四位，区分同物种的不同种群。

默认保留最近 120 个游戏日，首次运行从当前状态开始，刚建的地块只有创建后的记录。新种群出现前及迁出后的记录为空缺，不虚构历史。只有一个记录点时显示点和等待下一天的提示。重启游戏不保留历史，当前没有磁盘存档或长期降采样功能。

## 文件改动

| 文件 | 用途 |
| --- | --- |
| Assets/Scripts/UI/TileTrendHistory.cs（新增） | 独立运行时历史缓存。订阅每日模拟完成、地块变化和干预事件，只读取真实 BlockInfo/PopulationData。 |
| Assets/Scripts/UI/TileTrendChart.cs（新增） | uGUI 绘制折线、网格和单点，更新左右轴、日期、图例、等待提示。 |
| Assets/Scripts/UI/TileTrendPanel.cs（新增） | 一次性创建可编辑图表层级，运行时复用现有对象。 |
| Assets/Scripts/UI/GameInformationUI.cs | 初始化记录器，将选中地块交给趋势图，初次安装时把原详细文字移到图表下方。 |
| Assets/Scenes/WhiteBox.unity | 保存图表、缓存组件和所有 UI 引用。 |

新增脚本的 .meta 需一并提交。没有修改生态算法、建造规则、寻路或摄像机脚本。Editor 模拟器仍使用其原有记录，本次新增的是正式游戏 UI 可用的运行时记录器。

## 性能措施

- 以天为单位采样，不每帧扫描场景；模拟过程中的中间事件不单独采样，等待整天计算结束。
- 同一天干预替换当天记录，不重复追加。
- 固定容量环形数组覆盖旧记录，无需搬移全部历史。
- 按地块保存独立数据，面板关闭时继续记录，但不刷新图形。
- 图表比较历史对象与版本号，数据未变时不重建网格。
- 地块删除后清理其缓存；种群的存活记录完全超出保留区间后清理曲线缓存。
- 默认最多同时绘制 8 条种群曲线及一条植物曲线；超出时图例标注显示数量，全部种群历史仍保留。可在 Chart 组件调整上限（1～32）。

## Inspector 与 Hierarchy

- `Canvas → Tile Trend History → Retained Days`：保留天数，默认 120；在非 Play Mode 配置，下次运行生效。
- `Canvas/TileInformation/TileTrend`：图表整体位置和尺寸。
- `TileTrend/Chart → Tile Trend Chart`：线宽、网格颜色、植物颜色、最大显示种群数、植物轴是否自动范围。
- `TileTrend` 的 Title、各坐标轴、日期和 Legend：修改文字字体、字号和颜色。
- `Canvas/TileInformation/TileDetails`：下方原地块详细信息。

修改布局和样式后 Ctrl+S 保存场景。运行时会刷新真实文字内容，但不会重新设定已保存的布局和字号。新标题及普通坐标文字继续支持拖动窗口；关闭、Alt 点击、同类型唯一窗口规则沿用已有流程。

## 已验证与验收

已验证 Unity 编译及 Play Mode 帧推进；真实数据的图表网格与截图；两个地块各自的历史、切换后正确的数据引用；关闭窗口期间已有历史；缓存 130 天后只保留 120 天（最早 Day 11）；同一天替换；同物种不同 ID 独立记录；新种群早期记录为空；过期种群曲线清理；100 次无变化刷新后图形不重建；通过 UI 射线及事件转发验证图表标题拖动窗口；X 关闭解除遮挡；保存重开场景后组件和字体引用正常，原详细字号 25 保留。

验收：

1. 运行 WhiteBox，等待几天后 Alt 点击地块，检查上方折线、日期、图例及下方详情。
2. 关闭面板继续模拟，再打开，确认仍有关闭期间的历史。
3. 建造另一地块并运行几天；关闭旧面板后选择它，检查日期从该地块创建时开始，详情和趋势对应新目标。
4. 同一地块有两个同物种种群时，检查图例 ID 后缀不同且曲线分别记录。
5. 运行超过 120 天，检查显示区间保持最近 120 天。
6. 按住标题或详情文字拖动，点击 X 关闭；复核 Alt 拖地图、N 建造及多分辨率实际操作。

尚未进行数百地块的性能压测；缓存逻辑有明确容量上限，但实际耗时仍取决于地块和近 120 天内种群数量。完整鼠标游玩流程及各分辨率仍需人工验收。
