# 彩鸡引导接入说明

玩家文案、出现日、暂停状态、完成动作与功能开放顺序以 `Assets/Resources/TutorialFlow.json` 为准。教程气泡使用原有 `PaperPanel` 和 `PaperButton` 素材，位于安全区域内的屏幕下方。正文按实际换行高度调整面板；窄屏和长文案达到高度上限时可滚动阅读。

教程生态种子由配置中的 `tutorialSeed` 固定为 1。新游戏先完成 WhiteBox 初始种群和原有种子配置，再在第 1 天前应用教程种子；不调用 Unity 全局随机数初始化，也不消费开局随机抽取。读档保留存档中的生态种子。跳过或完成教程后沿用本局种子，避免中途改变生态随机序列。当前 WhiteBox 场景的原有 `replaySeed` 本身也是固定值 1，尚无单独的随机开局种子抽取实现。

| 流程 | 触发 | 系统控制 | 玩家操作 / 解锁 |
| --- | --- | --- | --- |
| 开场 | day0 | 暂停，初始地块与鸽鸽由原系统生成 | 阅读开场并关闭初始物种卡 |
| 观察 | day1–5 | 时间流动 | 观察数量变化 |
| 信息 | day6 | 暂停 | 查看鸽鸽、性状、地块和趋势；依次开放两类信息 |
| 变化 | day7 | 时间流动 | 认识变异 |
| 倍速 | day15 | 时间流动 | 开放暂停和倍速，等待 day50 |
| 进化目标 | day50 | 暂停 | 打开进化网、查看彩鸡线索、关闭进化网 |
| 升温 | day50 | 暂停到工具成功应用 | 开放温度工具，应用后观察生效过程 |
| 调整 | day76 | 暂停 | 开放撤销；再次查看进化网和彩鸡目标 |
| 自主培育 | day76 后 | 时间流动 | 开放湿度、两种植物工具及建造，等待真实演化事件 |
| 彩鸡诞生 | 实际解锁当天 | 暂停 | 完成主引导，开放剩余工具与经济操作 |

每一步的“出现日”是最早日。动作步骤必须收到相应的游戏事件才会前进；跨日步骤在等待时恢复时间。森林、水域等地形种类继续由原有生态解锁逻辑控制。森林迁徙、竞争和捕食属于后续条件触发提示，不阻塞彩鸡主线；当前主线只在自主培育提示中介绍相邻地块可能影响迁徙。

气泡右上角 × 可结束主引导，解除全部教程门禁。强制玩家完成操作的步骤会暂时禁用 ×，并提示完成当前操作后可跳过；完成操作或进入自由观察步骤后恢复。跳过不调用地形解锁 API。新存档保存当前步骤、等待状态和教程暂停状态；旧存档没有引导字段时维持完整功能。

## 待实际游玩检查

需要在 WhiteBox 场景用桌面与触屏分别走完 day0、day6、day50、day76 到彩鸡诞生，确认工具费用、生态性状和布局。特别确认最小支持分辨率下气泡与进化网、信息抽屉没有遮挡关键操作；本次静态编译不能替代 Unity Play 模式检查。
