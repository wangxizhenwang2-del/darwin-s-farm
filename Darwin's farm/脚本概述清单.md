# Darwin’s Farm 脚本概述清单

核查日期：2026-10-11。范围：当前项目 `Assets/` 下全部 **84 个 C# 文件**，包含示例与 Editor 工具，不包含 Unity 包、Library 缓存、Shader/HLSL 文件及外部工具。

这份清单根据当前代码的类型、方法和接入关系整理。它说明脚本职责，不表示所有脚本都已挂载到当前场景，也不代表本次重新执行了功能测试。

## 先理解几个概念

- **组件**：继承 MonoBehaviour，通常挂载在 GameObject 上；有些由运行时代码自动创建。
- **配置资产**：继承 ScriptableObject，保存可复用配置，通常在 Project 中创建。
- **数据/工具**：普通类型、枚举、静态工具或算法，不能作为常规场景组件挂载。
- **Editor 工具**：在 Unity 编辑器中使用，不属于正式游戏运行逻辑。
- **partial 拆分**：多个文件共同实现一个类，不应分别挂载。`MapTileColorTransitionSystem`、`SimulationController`、`PopulationVisualPresenter` 和 `PopulationSimulatorWindow` 均有此类拆分。
- `SimulationController.FoodWeb.cs` 虽然名称相似，实际声明的是 **FoodWeb 静态工具类**。

## 系统关系

```text
建造图鉴 → MapTilePlacementController → MapGridManager
                                      ├→ MapTileColorTransitionSystem：地表、起伏、装饰和障碍
                                      ├→ RuntimeMapNavigation：导航更新
                                      └→ MapSimulationBridge：地块生态数据与邻接
SimulationTime → 环境系统 / SimulationController → PopulationData 与 BlockInfo
生态数据与事件 → PopulationVisualPresenter → WhiteboxPopulation
                                          └→ PopulationTransitionVisual
PopulationMovementController → PopulationMotion / PopulationTileSpace
ClickToMove → NavMesh 与种群绕行
GameInformationUI → 读取地图和生态数据 → InformationWindow
BiomeOcclusionVisibility → 装饰淡化与被遮挡种群标记
```

## 阅读时容易混淆的地方

1. **PopulationData 是真实生态种群数据，WhiteboxPopulation 是场景表示。** 一个大形象和若干小形象只代表一个种群，不是实际个体数量。
2. **生态迁徙和地块内漫游属于两套职责。** 前者由 SimulationController 提交数据变化，后者由 PopulationMovementController 等控制场景运动，动画由 Presenter 接入。
3. **ColorSurface 是当前地面显示和碰撞依据。** 模型起伏采样到地表，装饰有单独的简化障碍；RuntimeMapNavigation 负责更新导航网格。
4. **旧黑色调试浮窗已于 2026-10-15 删除。** GameInformationUI 管理地块与种群信息；环境操作面板通过 EnvironmentToolSession 复用原环境控制器，模拟器仍用于诊断与测试。
5. **查看到脚本不等于它正在运行。** 是否启用还取决于场景/Prefab 的组件、运行时创建、Inspector 参数和配置资产。本清单未把未挂载脚本判为无用或可删除。
