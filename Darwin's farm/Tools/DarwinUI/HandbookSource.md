# 第一章 · 初识农场

## 1.1 你是谁？

### 欢迎来到达尔文农场！

在一颗遥远的星球上，一场关于生命的实验即将开始。

你是一名星际生态培育者，负责照料这片年轻的生命实验场。

在这里，你不需要指挥每一只生物。它们会自行觅食、繁殖、竞争，也可能迁徙到新的土地。

你真正能够掌控的，是它们生活的环境。

改变气候、调整食物供给、开辟新的栖息地，然后静静观察——生命将如何回应你的选择？

## 1.2 生命如何涌现？

### 生命会找到自己的道路

每一种生物都有自己的生存方式。

有的适应炎热，有的喜欢潮湿；有的擅长奔跑，有的依靠旺盛的繁殖能力延续种群。

当环境发生变化，原本适合生存的性状可能变成负担，而不起眼的特征也可能成为新的优势。

随着一代代生命更替，种群会逐渐发生变化。

当这些变化积累到一定程度，一个全新的物种便可能诞生。

**你无法直接命令生命进化，却可以改变它们进化的方向。**

## 1.3 你的目标

### 培育属于你的生命世界

你的旅程将从最初的鸡种群开始。

通过调整环境，引导它们沿着不同的演化道路前进，逐渐发现彩鸡、孔雀、灵感菇狸与鹿。

但发现新物种只是第一步。

每一种生命都需要食物与合适的栖息地，它们可能相互竞争，也可能因为环境变化而消失。

你的最终目标，是让**鸡、彩鸡、孔雀、灵感菇狸和鹿五种生命在同一个生态世界中共存**。

> **观察笔记**：进化成功不代表培育结束。让新生命在生态系统中延续下去，同样重要。

# 第二章 · 认识地块

## 2.1 一块土地

### 从一块土地开始

你的农场由一块块独立的土地组成，我们称它们为**地块**。

每块地块都有自己的温度、湿度、海拔和植物资源，也生活着不同的生物种群。

按住 **Alt 并单击鼠标左键** 点击地块，即可查看它的环境和生物信息。

你还可以调整地块的环境，改变生物所面临的生存条件。

**同一种生物，在不同地块上，也可能走向不同的演化道路。**

> **操作提示**：按住鼠标中键拖动以平移镜头，滚动鼠标滚轮放大或缩小画面。

## 2.2 不同的地貌

### 气候塑造土地

你可能遇见干燥的荒漠、湿润的雨林、寒冷的雪山，或炽热的火山。

一块土地的地貌由**温度、湿度和海拔**共同决定。不同地貌也拥有不同的植物资源条件。

改变地块环境，可能让它逐渐呈现出另一种地貌。

> **操作提示**：查看物种适宜的温度与湿度，并与地块环境进行比较。

## 2.3 相邻地块

### 让农场向外延伸

除了最初的土地，你还可以向周围扩展地块。

相邻地块可以拥有不同环境，为不同种群提供栖息地。地块之间能够通行时，生物还有机会自行迁徙。

海拔相差一级会阻碍通行，相差两级则无法直接迁徙。

**扩展地块，也是在创造新的演化机会。**

> **操作提示**：按 **N** 打开土地建造栏，从下方栏拖动土地到目标格子进行建造。

# 第三章 · 环境与资源

## 3.1 使用环境工具

画面左侧有五种环境工具：**植物增量、植物存量、温度、湿度、海拔**。

每种工具都有不同档位，用来调整变化方向和强度。

**操作步骤**：选择左侧工具 → 选择档位 → 点击地块 → 点击「应用」。

要取消已有干预，重新选中对应工具与地块，点击「撤销」。

## 3.2 认识五种工具

| 工具 | 用途 |
|---|---|
| 植物增量 | 调整植物每天恢复的数量，影响长期食物供应 |
| 植物存量 | 立即增加或减少已有植物资源 |
| 温度 | 让地块逐渐升温或降温 |
| 湿度 | 让地块逐渐变湿或变干 |
| 海拔 | 改变地块高度，影响地貌与迁徙通道 |

## 3.3 工具档位

| 工具 | 小幅调整 | 大幅调整 |
|---|---|---|
| 植物增量 | ±5,000 / 游戏日 | ±15,000 / 游戏日 |
| 植物存量 | ±10% | ±30% |
| 温度 | ±25 | ±50 |
| 湿度 | ±25 | ±50 |
| 海拔 | +1 或 −1 | 无第二档 |

> 档位数值来自当前策划候选配置，正式发布前请与 Unity 实际数值核对。

## 3.4 环境与生命

环境变化既会影响生物的生存，也可能引导性状变化。

例如，食物充足可能有利于更大的体型；长期稳定的食物供应可能有利于繁殖；寒冷则可能让种群逐渐适应低温。

**你改变的是环境，而不是直接修改生物。**

# 第四章 · 认识生命

## 4.1 认识生物

农场中生活着各种生物，每种生物都有自己的习性和生存需求。

按住 **Alt + 鼠标左键** 点击地块上的生物，可以查看详细信息，包括种群数量、性状和生存状态。

游戏主要模拟**种群**，而非逐只模拟动物。

## 4.2 五项性状

| 性状 | 作用 |
|---|---|
| 适温 | 最适应的温度 |
| 适湿 | 最适应的湿度 |
| 运动 | 活动与迁徙能力 |
| 体型 | 影响食物消耗和生存方式 |
| 繁殖 | 影响种群产生后代的能力 |

性状可能随环境和时间变化。

## 4.3 生物网与进化网

按 **M** 打开生物网与进化网。

- **生物网**：查看不同生物之间的生态关系。
- **进化网**：查看可能的进化路线。

在生物网中**左键点击某种生物**，可以查看它的信息与进化需求。例如，需求提示可能出现：温度 `++`、湿度 `−` 等。

`+` 表示提高，`−` 表示降低，`≈` 表示接近目标；重复符号表示需要更大幅度调整。

## 4.4 观察生物的变化

生物不会因为一次环境操作就立刻进化。

观察五项性状、种群数量和进化需求，判断调整是否有效。

> **观察笔记**：想培育新物种？先在进化网中找到目标，再尝试创造它需要的环境。

# 第五章 · 生态与演化

## 5.1 食物与生存

每一种生物都需要食物才能生存和繁殖。

食草生物依靠植物资源，食肉生物则需要捕食其他动物。

食物充足时种群可能壮大；食物不足时，种群可能下降甚至灭绝。

## 5.2 竞争与捕食

同一块土地上的生物会相互影响。

多个种群可能争夺同一份食物，捕食者也会影响猎物数量。

**一个种群的变化，可能影响整块土地的生态平衡。**

## 5.3 迁徙与扩散

当相邻地块出现更适宜的生存环境时，生物可能迁徙过去。

迁徙受到运动能力、地块环境与海拔连通性的影响，并不保证成功。

> **观察笔记**：建造环境不同的邻地，也许能为生物创造新的生存机会。

## 5.4 适应与变异

环境变化时，生物也可能逐渐改变自身的性状，以适应新的生存条件。

例如，寒冷可能促使种群适应更低温度；食物供给变化可能影响体型和繁殖。

这些微小的性状变化称为**变异**，但变化未必都符合你的预期。

## 5.5 变异与进化

一次变异通常只带来微小变化。

当变异不断积累，使种群五项性状接近目标，并持续满足数量与时间条件时，一部分原有种群便可能**分化成新的物种**。

新物种仍需要食物与生存空间，也会面对竞争和捕食。

> **观察笔记**：进化来自变化的积累；新生命诞生后，也需要生态环境支持它继续生存。

# 第六章 · 引导进化

## 6.1 选择进化目标

按 **M** 打开进化网，选择想培育的物种，查看五项性状需求。

`+` 代表需要提高，`−` 代表需要降低，`≈` 代表已经接近目标。符号越多，所需调整幅度越大。

## 6.2 用环境引导性状

| 想要的变化 | 可以尝试的操作 |
|---|---|
| 适温 ↑ / ↓ | 升高 / 降低温度 |
| 适湿 ↑ / ↓ | 增加 / 降低湿度 |
| 运动 ↑ | 创造更有吸引力的邻地，鼓励迁徙 |
| 运动 ↓ | 制造地形隔离，或降低邻地吸引力 |
| 体型 ↑ / ↓ | 增加 / 减少植物存量 |
| 繁殖 ↑ / ↓ | 增加 / 减少植物增量 |

操作只能**引导方向**，不能保证每次都产生相应变异。

## 6.3 抓住进化时机

可以先集中引导一项性状，再根据进化需求调整策略。

当某项性状接近目标时，可以考虑撤销当前干预，转而关注其他性状。

> **观察笔记**：留意进化需求的变化；环境干预结束后，种群仍会继续自然演化。

## 6.4 迎接新物种

当五项性状接近目标，并持续满足进化条件时，种群便有机会正式分化。

一部分原有种群成为新物种，母种群仍然保留。

**进化成功只是开始，让新物种存活下来同样重要。**

# 第七章 · 生命的价值

> **功能状态**：本章描述规划中的经济玩法；当前生态测试默认关闭经济限制，待功能开放后再核对游戏内名称、产出与消耗。

## 7.1 生物能

生命不仅会消耗资源，也会为农场带来珍贵的**生物能**。

每一种生物都会随着时间自然产生生物能。种群越繁盛，积累的生物能也可能越多。

生物能是你培育这颗星球的重要资源。

## 7.2 培育的代价

改造环境、建造土地，都需要消耗生物能。

不同操作有着不同的消耗。合理分配生物能，才能持续开展生态实验。

> **观察笔记**：不必急着改变所有土地，先让已有的生命繁衍壮大，也是一种策略。

## 7.3 丰富的生命，更大的价值

每一种生命都有独特的生态价值。

从食草生物到捕食者，从原始物种到新生物种，它们共同构成一张复杂的生命网络。

**培育更多样的物种，建立更丰富的生物网，便能获得更高的生态价值与生物能收益。**

这也是达尔文农场的经营之道：让生命繁荣，再利用生命带来的能量，创造新的生存机会。
