# HUD 与 Alt 建造切换

- PC 工具栏由 200×500 收窄至 170×500。图标保持圆形，五个点击区域和选中反馈同步移动，展开操作面板维持原尺寸。
- 移动端天数、倍数固定到安全区域右上角，生物能留在左上，中间预留新闻空间。
- 移动端取消独立暂停入口，左侧为环境工具、定位玩家、建造地块。倍数按钮循环：1× → 2× → 4× → 暂停 → 1×。PC 倍数按钮行为保持原规则。
- PC 建造模式下按住左 Alt 或右 Alt，优先退出建造并取消待放置预览，恢复正常浏览与地块／种群信息选择。Alt 的处理早于信息点击和放置逻辑，按住 Alt 时 N 不重新进入建造。

验证：Unity 编译与 C# diff 检查通过；170 宽工具栏的五个实际点击区域和功能映射通过；移动端完整倍数循环、独立暂停入口隐藏、正常及带安全边距的右上布局通过；模拟 Alt 与鼠标输入验证了左 Alt 退出建造后查看地块、右 Alt 查看种群、取消拖动预览及恢复地图浏览，没有新增地块。测试使用的虚拟输入设备已移除，物理设备与输入设置均恢复。

场景已保存为 `Assets/Scenes/WhiteBox.unity`，显示模式 Auto，已退出 Play 模式。未做手机真机验证。
