# 苔原地块 v2：岩石细化

在 v1 已保存场景的基础上调整岩石，并保留独立的 v2 文件。

- 岩石使用不规则斜切轮廓、窄倒角与凹陷切面，增加真实几何层次。
- 增加局部裂纹、短排线和底部碎石，岩石墨线可单独隐藏。
- 积雪根据新的岩石表面生成，并带有薄厚度。
- 地块仍为 17 × 17 米，Y 轴向上，底部中心位于原点。
- 整体共 100 个网格、10,626 个三角面。

文件：`Tundra_Rocks_v2.ma` 为 Maya 原生场景，`Tundra_Rocks_v2.fbx` 为模型导出，`Tundra_Preview_v2.png` 和 `Rocks_Detail_v2.png` 为模型的实际渲染。

Maya 文件重新打开、FBX 重新导入均通过验证，尺寸、网格数和三角面数一致；未发现非流形边或缺少 UV 的网格。详细结果见 `reopen-validation.json`。

当前仍为带基础配色的低多边形模型，精细手绘贴图和游戏内材质接入可继续在此基础上制作。
