# V048 rule mapping against the checked-out Unity project

| Topic | Existing project behavior at baseline | Current implementation / verification |
| --- | --- | --- |
| Same-species split | Near-K local branch, target approach, later merge | Removed from daily route; compatibility gate reports retired. Formal species evolution is the only local split in daily ecology. |
| Formal split size | 10–100 clamp, old lineage replacement semantics | 10% of living mother count, positive half-up integer rounding, no 100 ceiling; real stock limits larger-body offspring. |
| Parent and child | Child inherited branch state; old locks could persist | Mother retains actual five traits. Child gets target template. Both clear previous personal target, influence, protection, and selection state. |
| Food and bodies | Birth and predation energy did not track real animal body material | Body material is created from funded newborn intake, transferred on predation/migration/evolution, removed with harvest, and sent to detritus on death or shrink conversion. |
| Natural traits | Deterministic best candidate with heuristic bonuses | One weighted event per population/day; climate follows actual T/H; natural strategy requires positive model forecast gain and a density opportunity draw. Player influence has separate eligibility. |
| Player tools | Real environment effect, no trait-pressure handoff | Successful technology commit forwards a typed event to the model; its physical T/H/S/R effect continues independently. Current plant technology changes S and R together, as implemented in Unity. |
| Direct Bar economy operation | Changed two traits instantly | Old operation now explicitly rejects with a rule explanation. UI still presents the legacy operation; a UI owner should remove or replace that affordance. |
| Replay | Global Unity Random in ecological movement, random lineage IDs | Event-keyed model draw, canonical initial IDs, stable model ordering, daily model/environment hashes, full ordered player technology actions in a fresh Play-mode Editor process. |

The user-supplied ZIP is a specification and prior research source. Its Python numbers and standalone fixture are not treated as the Unity oracle. Known limitations and measured outcomes are recorded in the final test report.
