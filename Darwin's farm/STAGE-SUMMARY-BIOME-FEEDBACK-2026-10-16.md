# 地块转换反馈阶段总结 · 2026-10-16

建议提交标题：**增加地块转换渐变与装饰生长反馈，完善连续切换和预览检查**

环境变化触发地形类型转换时，原来会直接替换地面颜色、树木和石头。本阶段为这个过程增加约 1.1 秒的视觉过渡，帮助玩家看清地块正在变化。按本次要求，不添加地形名称提示。

## 转换表现

- 地面颜色从当前显示颜色平滑过渡到目标颜色，同时处理受邻接地块影响的边缘颜色。
- 旧树木、草丛和石头缩小退场，新装饰按位置错开时间，从地面逐渐长出来。
- 装饰缩放围绕地面锚点进行，避免模型因自身原点位置不同而悬空或向错误方向收缩。
- 提供动画开关和时长配置，默认时长为 1.1 秒；效果使用实际时间播放，不随生态模拟倍速加快。

## 刷新与连续切换

- 初次加载、放置新地块和未改变地形类型的普通环境更新，不会让现有装饰重新播放生长动画。
- 未转换的地块复用已有装饰；地面重建后重新对齐支撑高度，避免无关地块反复销毁和生成模型。
- 连续转换从当前显示颜色和装饰缩放继续过渡，及时清理退场模型，避免旧装饰残留。
- 兼容没有对应装饰预制体的地形，仍可完成地面颜色变化及旧装饰清理。
- 系统禁用时将当前显示恢复到目标状态，并清理尚未完成的退场对象。

## 地形、碰撞与移动

- 反馈只插值地面颜色和装饰显示，不缩放地块根节点或动物。
- 新装饰的碰撞体、导航障碍保持完整尺寸；旧装饰退场时立即停用旧障碍，避免同时保留两套阻挡。
- 地形高度变化时同步调整装饰和障碍的支撑高度；地面顶点数量变化时按水平位置匹配颜色。
- 导航继续随实际地形修改更新，视觉动画不会逐帧请求重建 NavMesh。
- 环境分类、生态结算、种群数量和原有寻路规则沿用现有流程。

## 预览与检查入口

- 新增 `BiomeTransitionChecks`，提供 Play 模式下的预览和实际运行检查。
- 预览菜单：`Tools → Darwin's Farm → Animation → Preview Biome Feedback (Play Mode)`。
- 预览会暂停生态结算、调整镜头，并演示“荒漠 → 草原 → 森林 → 荒漠”；退出 Play 后恢复场景。
- 完整检查通过 `BiomeTransitionChecks.Run()` 启动，结果可从 `BiomeTransitionChecks.Result` 查看。
- 已录制本地 GIF 预览，保存在项目的 `.utmp/biome-feedback/` 中；该目录已被 Git 忽略。

## 已完成验证

- Unity 编译通过，0 错误、0 警告。
- 实际运行验证荒漠、草原、森林的往返转换，确认地面显示中间颜色，装饰完成退场和出现。
- 连续中断转换、普通环境更新、未变化的相邻地块、缺少装饰预制体，以及禁用时的清理检查通过。
- 检查期间装饰碰撞体尺寸保持稳定，动物水平位置与实际地面行走位置一致。
- 确认视觉过渡结束前后，导航不会因动画持续重复重建。
- 原有地形变化回归通过：覆盖记录过的卡住位置、0／1／2 高度往返，以及数量为 80、600、1200 时脚下新增障碍后的安全恢复和持续移动。
- 单独运行预览入口通过；测试结束后退出 Play，恢复原场景和测试前的后台运行设置。
