# 历史残留、安全清理与兼容说明

1. 普通 5% `local_split` 生产逻辑已停用。`OnLocalSplitResolved`、`ReadSplitGate`、`SplitGateInfo`、`nextLocalSplitDay`、`splitFounderFraction` 等仍被场景序列化、表现层、编辑器导出或旧回归夹具引用，保留为兼容内容。旧 `IsLocalSplitPair` 也被反射夹具引用，未强删。旧参数存在不代表机制仍会执行。
2. `ecologicalNichesEnabled` 是旧场景的序列化字段，已有场景可能为 true；有效运行态只由新天空/水域独立开关决定。旧 `SetEcologicalNichesEnabled` 仍同步设置两项，供现有编辑器调用；旧只读属性返回有效状态。
3. 原 `Assets/BiowebV46/bioweb.json` 包含 UI 布局及少量旧模板值，保留以防地图与外部依赖受损。V6.1 原始字节另存 `Assets/Resources/V61Bioweb13.json`；白盒启动时校验其哈希与导入的 SpeciesData 引用。V6.1 补丁未改场景、Prefab、既有 ScriptableObject 引用或 UI；后续用户授权合并的空中种群提交修改了 `WhiteBox.unity` 与字体资源，详见《合并审阅清单》。
4. 详细生态 `Debug.Log` 由 `EnableEcologyConsoleLogs` 控制，默认 false；现有 `OnEcologyEvent` 订阅方仍可在测试时收到诊断。日常账本不写盘，模型哈希仅在显式诊断模式下计算。错误与警告保留。编辑器菜单的旧测试输出属于手动运行工具，未清除历史证据。
5. 旧 V50 环境 smoke 的即时 R 预期已经过时，运行结果保留为历史失败证据；新增 V6.1 环境审计是现行检查。旧 Agent V048 夹具因项目现有依赖变化无法作为新规则验收，记录保留。没有删除既有报告、JSONL、CSV、回放输入、种子或版本归档；本轮备份放在独立 `Backup/`，运行时不加载。
6. 编译阻塞集中在既有 `EnvironmentToolSession.cs` 使用 `MonsoonAnchor`、`PlantChange`、`TemperatureOffset`、`HumidityOffset`、`HasMonsoon` 和四参数构造器，而当前 Model 无对应定义。为了保护其他开发者的 UI 合约，本轮未修改该文件或扩张 Environment Model 公共接口。
