# 《达尔文农场》规则统一规范 v0.5（Task12 优先依据）

**发布日期：2026-10-17；状态：用户已冻结玩法约束 + 待源码核对的执行细节。**

> 本文件是本轮对旧 Agent 提示词的订正与单一规则来源。它**不是声称现存 Unity 代码已经全部符合**。遇到冲突，先出差异报告、写回归，再在隔离分支最小修复；禁止把未测试的实验公式冒充正式规则。

## 0. 首要订正与目标

- 世界的地块是**四边形**，不是六边形。移动/迁徙图由 `BlockInfo.neighbors` 记录的**共享边邻接**决定；不自动接入斜对角、远距离或六边形的6邻居。每地块实际可用邻接数受边界、断连与地形限制影响，非必然恰好4。
- 小范围机制测试：**2–4个有连接的四边形地块**即可。综合共存场景：按五种生物的生态位需求决定**必要的最少地块**，不强制7个。
- 终点是**五种生物共存，四次合法正式进化**：初始鸡；路线 A：鸡→彩鸡→孔雀；路线 B：鸡→灵感菇狸→鹿；生存名单：鸡、彩鸡、孔雀、灵感菇狸、鹿。四条进化边必须以当前生物网核验；图不支持时如实报 BLOCKED，不得篡改图凑成功。
- 集成验收的迁徙门槛是**两次有真实生态原因的源→目标完整迁移**，不是20次；同时在独立测试证明一次同种合并与一次有意义的迁徙拒绝。禁止为统计数字人为制造大量迁徙。

## 1. 数据与版本边界

| 对象 | 规则 | 代码核对事项 |
|---|---|---|
| 地块 | 四边形、显式邻接；温度/湿度 0–100；海拔 0/1/2；植被存量、恢复量、上限 | `BlockInfo`、neighbors 的实际导出与网格创建逻辑 |
| 物种 | `SpeciesData` 为默认模板；进化网/食物网按真实 JSON | `source-bioweb13.json` 若存在；不要信任旧 ZIP 缺失的图 |
| 种群 | `PopulationData`，同一种在不同地块可有不同状态；迁入已有同种要合并并处理性状/余数/身体资源 | 检查用 `speciesId + blockId` 识别，不要跨地块误合并 |
| 食物链 | 设计术语：L0 植物生物量（不建 Population）；L1 食草；L2及以上捕食更低级 Population | **特别注意**目前 `LandLifeRules.cs` 可见 `trophicLevel==0` 被作为“食草动物”处理——源码编码与策划层编号存在偏移。必须用实际 `FoodWeb.CanEat` 判定，不能盲目将代码 level=0 改为植物或 +1 |
| 时间 | 默认 `basicDayLength=5秒/游戏日`，倍速独立控制 | 真实项目可配置值优先；不能偷偷改授时缩短体验目标 |
| 经济 | 玩家生物能、售价、货币成本等本轮禁用 | 不等于生态物质免付费，出生/进化能量账照常 |

## 2. 玩家十按钮：操作目标、时序和撤销

玩家控制的是**环境**，不允许按钮直接把生物的性状、数量、K 设置成预期值。操作日志逐条记录 `action_id, day, block_id, kind, sign, intensity, stage, cancelled_at, recovery_completed_at`，固定 seed + 日程必须可重放。

| 环境按钮 | 对环境的直接作用 | 定向性状压力（主要 / 次要） |
|---|---|---|
| 存量 + | 即时增加现存可用植物存量，仍受容量与真实事务记账约束 | 体型 ↑ / 繁殖 ↑ |
| 存量 − | 即时减少植物存量 | 体型 ↓ / 运动 ↑ |
| 增量 + | 渐变提高植被恢复量 | 繁殖 ↑ / 运动 ↓ |
| 增量 − | 渐变降低植被恢复量 | 繁殖 ↓ / 体型 ↓ |
| 温度 + | 渐变升温 | 适温 ↑ / 体型 ↓ |
| 温度 − | 渐变降温 | 适温 ↓ / 体型 ↑ |
| 湿度 + | 渐变加湿 | 适湿 ↑ / 繁殖 ↑ |
| 湿度 − | 渐变减湿 | 适湿 ↓ / 体型 ↑ |
| 邻地吸引 + | 启用/提高相邻地块吸引信号，依真实连接计算 | 运动 ↑ / 无强制次要项 |
| 邻地吸引 − | 取消/降低相邻地块吸引信号 | 运动 ↓ / 无强制次要项 |

**时序（温度、湿度、增量）：** 最近期望的三阶段是 **进入25天 → 维持150天 → 恢复100天**。输入可在任何阶段取消，不必等时间到；取消时退出当前目标的持续引导，**从当前实际环境值**向该地形原本的基线缓慢恢复，既不瞬间跳回默认，也不重新走完整进入与维持阶段。撤销后在保护有效条件下继续兑现已有保护，失效后按自然回落而非即时回档。若现有 Unity 具体插值/保护窗口实现不同，输出差异及对照测试，按本用户规则修正。

**存量 ± 是即时事务：** 不存在还可“撤销”的存量持续 Buff。玩家可施加相反方向的新合法存量操作以修正剩余库存，但不能追溯恢复已经吃掉的草、已经发生的死亡/繁殖/进化；若 UI 有 Undo，应区分“撤销尚未生效的请求”和“反向操作”，不能悄悄重写历史。

**邻地吸引 ± 是持续性开关/状态调节：** 能随时取消，取消后停止继续施压并解除吸引；既有迁徙和已发生性状改变不倒带。动作同时控制一个地块时，应有确定性叠加/替换与撤销规则，避免覆盖其他作用；本轮只测试合法现有实现，不自行发明无限叠加。

**长稳态观察应从“最后一次正式进化、最后一次玩家操作、全部持续环境效果恢复完成”三者中的最晚日期开始。** 不允许关闭 UI 后让仍在维持150天的隐形操作继续起作用却称为“无人干预”。可将“操作已撤销但自然恢复中”单独作为恢复期测试，不计入严格自然稳态窗口。

### 撤销必须单独验证的最少场景

- `CANCEL_ENTRY`：进入阶段第10天取消 → 直接从当时值恢复，不继续朝旧目标升温/加湿。
- `CANCEL_HOLD`：维持阶段取消 → 无突跳，逐渐回归默认。
- `CANCEL_RECOVERY`：恢复阶段重复撤销 → 幂等，不重复退款/清空，不重置其他地块操作。
- `CANCEL_AND_REAPPLY`：撤销旧增量后开启新反向操作 → 清楚记录覆盖范围，适应性与变异席位不双计。
- `CANCEL_STOCK`：已经执行的存量瞬时交易不能回滚生态历史；可以通过一笔新的合法反向操作减少/增加**当前剩余**库存。
- `CANCEL_ATTRACTION`：关掉吸引后后续运动压力消失，已发生合法迁徙不返回。
- `CANCEL_EVOLUTION`：撤销发生在正式进化之后，不允许倒转母子种群或取消已完成进化。
- 固定 seed 重跑 `CANCEL_*` 结果一致，日志事件和恢复时序一致。

## 3. 五 Bar、定向变异、自然选择与保护

- 五 Bar = 适温、适湿、运动、体型、繁殖。一次自然/定向变异**最多改变一项性状、幅度最多±1**；每群每天共享一个变异机会，不允许同一天对五项各自独立抛概率而连跳。
- 玩家近期引导的项目有**引导保护**；五 Bar 全部满足目标容差有**达标保护**；缺乏主动目标时追踪**最近可达目标**作为自动方向。三类保护的优先级和有效期应与冻结版一致，并在日志显示保护原因。
- **适温/适湿不可被短期保护**，也不计短期收益；它们依长期温湿压力自然靠齐。温湿与运动/体型/繁殖共用变异席位，**温湿竞争优先**。只因自然变异导致了适温/适湿变化，不得额外触发短期运动/繁殖/体型加减。
- 短期性状压力来自合法环境操作，不能当作按钮直接 `setTrait`。操作撤销后，不再施加新引导；保护与延迟自由回落仍按有效期/范围生效，不能瞬间恢复性状模板，也不能无限永久保护。
- 自然选择的候选变异需要**预期正收益**：先基于真实食物份额、气候适应、捕食压力、能耗及竞争计算候选条件，再接受/拒绝；即使数量接近 K，也允许极小概率的有利变异。
- `N/K≈0.9` 附近自然变异频率明显降低；`N/K>0.9` 几乎停止但不能完全阻断已证实有利的生态位补偿；`K≈0` 需要独立安全处理，不产生 NaN/无限率。
- 引导与自然选择不得为完成目标直接修改 `SpeciesData` 模板或在测试代码里写最终 Bar。

## 4. 正式进化（不是普通生态分裂或迁移）

- 只能按真实物种图的合法进化边；五项性状均落入图定义容差、满足正常真实门槛和持续时间后才可触发。当前实验 `evolutionTraitTolerance=5` 等代码参数不自动等于最终冻结门槛，应核对用户现有配置。
- **正式进化的目标比例为母群当前数量10%，不设100只上限**（整数取整方式以当前正式代码核对）；不够的真实生物量付款时必须**减少可负担的新种数量**，不能凭空造物质。门槛不足可拒绝，但不能额外套普通迁徙的100只上限。
- 母群数量扣减，子群新建目标物种并**立即使用目标物种模板默认性状**；子群不继承母群三重保护、不继承短期引导收益，不无条件继承母群目标追踪。母群解除既有引导保护，开始正常自然回落/追踪，环境操作系统恢复正常状态。
- **同一地块已有彩鸡，就不能再次在该地块正式进化出彩鸡**；其他目标物种同理按“本地已存在目标种”拒绝重复产生。检查本地与全局边界，不能因另一个地块有目标而误阻止合法本地事件，除非图规则另有明确规定。
- 特别区分旧 `splitFounderFraction=0.05`：源代码此字段可能属于**自主生态分化**，并非“正式进化10%”。不能简单全局改成0.1而破坏既有自主分化；先核对真实函数、事件类型与账本。迁徙也不是进化。
- 进化事件：day、block、source、target、N母群之前/之后、N子群、新物种模板性状、可支付植物/猎物生物量、应付/实付、保护清除、事件原因。

## 5. 迁入迁出（四边形共享边拓扑）

- 候选邻居来自真实连接的四边形**共享边**，不是六角格“六邻居”；**不默认斜对角可跨越**。无连接不能迁移。`neighbors` 中如有非共享边连接，应单独报告地图逻辑差异。
- 触发考虑目标与原地的适应度差 `Δfitness`、原地 `N/K` 压力、目标的资源/可用空间和迁徙冷却；有生态收益才倾向迁徙，不能为完成事件数强制瞬移。
- 高差绝对值 0 允许正常地形迁移；相差1 允许受惩罚/低概率迁移；相差2 阻止（按已冻结陆地迁移规则）。海陆空跨生态位不是本轮自动免费转换。
- 单次拟迁徙少于10只取消；超过100只只迁100只。注意这**仅适用于迁徙**，不适用于正式进化10%。
- 目标超载要降低实际成功概率/可迁数量，且影响迁入后动态 K；不能把目标地拥挤和源地拥挤混为同一个修正。
- 同物种迁入时合并种群，保留一致的基因/体量及整数结算余数规则；迁徙后执行全局或局部冷却，避免同一天反复往返、链式转移和双重计费。
- 迁移守恒不应把同日出生/死亡算成迁移：每次 `N_source_before - migrants = N_source_after` 和 `N_dest_before + migrants = N_dest_after` 在独立迁移事件结算区间成立；一个完整游戏日还要拆分出生、死亡、捕食、进化流量。
- **验收最低只要求 2 次真实成功迁移**，加一次同种合并和一次合法拒绝测试。概率低导致没有自然成功事件时，允许单独控制种子、环境压力做机制验证，但必须注明场景差异、不能用测试夹具直接瞬移冒充真实函数运行。

## 6. 生态资源、捕食和动态 K（原则）

- 所有草食者竞争同一份植物实际存量；大小体型可影响植物生态位的**分配权重**，但不可因“两个层”复制出两份实体草。
- 每日植物再生是合法外源生态输入；草的**存量与再生速率分开**。先为成年个体分配维护需求，再用真实剩余预算支付出生。
- 捕食必须随可捕猎物数量降低而减弱，猎物实际减少、能量实际迁移；捕食者 K 随猎物更新和竞争捕食者改变，不能在猎物稀缺时仍按固定比例无限捕杀。
- 动态 `K_est` 是**长期可持续食物、竞争、捕食下的容量估计**，不是 `speciesAmount` 的强制截断，不可设各个物种写死不同 K。迁入、灭绝、进化、新生、捕食、存量/再生和环境改变后必须按一致的时序重估。
- `K_est`（环境估计）与 `carryingCapacity=本日摄入/个体需求`（经验摄食尺度）可能是两个不同指标，不能在日志里混为同一数；详见 `MODEL_FORMULAS_V05.md`。
- 当前 L0猎物更新配额算法是**实验性可选机制**，旧验收只在被测场景里证明配额无违例；不是所有食物链、所有地块都验证成功，不能写成已全部冻结。
- 小种群整数出生需要能积累概率/机会，但不能攒未付款婴儿，也不能在没生下婴儿时收费等额繁殖死亡；所有出生、死亡、猎物身体物质、尸体回收和进化付款须有账。

## 7. 多阶段验收与真实证据

1. 先核真实工程、Graph、版本，跑原旧 A–D 回归与 Task9/10 已观察的彩鸡/菇狸对照；旧代码数值差异需注明。
2. 再做2–4块四边形迁徙与撤销的 **定点机制测试**，通过后才纳入综合生态测试。
3. 在同一世界以鸡为初始种，通过4次合法事件分别生成彩鸡、孔雀、灵感菇狸、鹿；最终五种同时存在。
4. 撤销/结束持续环境操作，等全部正在恢复的环境效果完成后，才开始**至少1000日无操作**的共存期，观察5种数量、动态K、食物份额、迁徙、捕食和资源余额；先保障不灭绝，再检验最后200日合理波动是否属于稳定共存。
5. 初步固定种子240，至少复现一次；再用241、242同一策略挑战，不许为某一种子调公式或偷偷重放失败时间窗口。各 seed 的 `PASS/FAIL/BLOCKED/NOT_RUN` 必须分开。
6. 只能根据真实 Unity 日志宣布 Unity PASS；离线模型成功与测试场景运行完成分别独立标注。

### 注意：不可自行定夺的设计变更

不擅自改变“四边形拓扑/两条演化链/五种共存目标/10%正式进化/十按钮压力方向/撤销权/单次变异±1与统一席位/三重保护/零经济成本”。其他具体分配公式可以研究、修改并验证，但必须可回退，遵守当前现有生态守恒和生物图约束。
