# 手机适配第一阶段：触控输入接入

本阶段为现有 WhiteBox 场景增加触控输入，目标为 Android 手机横屏。游戏仍使用现有 uGUI、Input System、NavMesh 和生态数据；手机 UI 排版、建造按钮和 Android 实机打包验收在后续阶段完成。

## 已接入的操作

| 操作 | 行为 |
| --- | --- |
| 轻点地面并松手 | 请求玩家移动，沿用 ClickToMove 的寻路与种群绕行 |
| 轻点种群或其遮挡标记 | 打开种群信息；窗口已占用时保留旧目标并消耗点击 |
| 长按地块约 0.45 秒 | 打开地块信息；种群优先于地块识别 |
| 单指拖动场景 | 平移地图，超过阈值后才开始；松手不触发点击 |
| 双指捏合／移动 | 按现有缩放范围缩放并平移，保持相机角度 |
| 在已有 UI 上触摸 | UI 处理事件，场景不接收这次手势 |

同类信息窗口仍不能重复打开或自动替换目标；两类窗口可以共存，关闭按钮分别解除占用。

## 文件与接入位置

- `Assets/Scripts/Input/MapTouchGesture.cs`：独立的手势状态判断，处理点击、长按、拖动、双指和取消。
- `Assets/Scripts/Input/MapTouchInput.cs`：使用 EnhancedTouch 读取手指，判定 UI 起点归属，向已有控制器发出请求。
- `Assets/Scripts/Input/Editor/MapTouchGestureChecks.cs`：手势冲突回归检查。
- `Assets/Scripts/Controller/Camera/ScreenEdgeCamera.cs`：共用平移、缩放和返回玩家入口；触控期间暂停自动跟随，避免长按目标漂移。
- `Assets/Scripts/Controller/ClickToMove.cs`：共用屏幕坐标移动入口；触控等到松手才发新命令，已有路径继续更新。
- `Assets/Scripts/UI/GameInformationUI.cs`：共用信息选择入口；触控增加可调整的点击容差。
- `Assets/Scenes/WhiteBox.unity`：Main Camera 已挂载 MapTouchInput，并绑定已有相机、Player、信息 UI、建造模式及放置控制器。

没有增加第二套相机、玩家、生态模拟或导航网格。Input 文件夹及脚本对应的 `.meta` 文件应一起提交。

## Inspector 参数

选中 `Main Camera → Map Touch Input`：

- **Drag Threshold Pixels**：单指拖动判定距离，默认 16，按 720 像素屏幕高度换算；屏幕分辨率越高会等比例扩大。
- **Population Pick Padding Pixels**：种群图像边缘的触控点击容差，默认 12，同样按屏幕高度换算；电脑原有点击范围保持原值。
- **Long Press Seconds**：长按触发时间，默认 0.45 秒，使用不受模拟倍速影响的时间。
- **Simulate Touch With Mouse**：仅用于 Editor 的单指触控测试。默认关闭；打开后鼠标模拟触摸，场景鼠标操作由触控入口处理。切回电脑操作时关闭。
- 场景引用已绑定，首次验收不需要手动拖入。

## 手势冲突规则

1. 触摸按下时不立即执行玩家移动。
2. 超过拖动阈值后，本次手势始终视为拖动，回到起点也不会变成点击。
3. 加入第二根手指会取消待执行的单指点击或长按。
4. 双指变成单指后，等待所有手指松开，再开始新的手势。
5. 从 UI 开始的触摸，即使之后移到场景也不会操作地图。第二根手指按在 UI 上时不启动地图缩放。
6. 切换建造／预览状态、触摸被系统取消、失去焦点或进入后台时，清理当前手势。
7. 在窗口入场动画完成后再拖动窗口。

## 编辑器验收

1. 打开 `Assets/Scenes/WhiteBox.unity` 并进入 Play Mode。
2. 选中 Main Camera，打开 `Simulate Touch With Mouse`，再把焦点切回 Game 窗口。
3. 轻点可走地面：玩家在松手后接收移动指令。
4. 轻点鸡的形象／遮挡标记：只打开对应种群信息，不让玩家向其移动。
5. 在空地长按约 0.45 秒：打开地块信息，松手不会补发移动指令。
6. 两类窗口都打开后，关闭其中一类，检查另一类仍然显示；同类窗口打开时不替换目标。
7. 拖动地图并回到按下位置再松手：只平移，不打开信息、不发送移动指令。
8. 信息面板动画完成后，在文字区域拖动：面板可移动，地图不接收这次触摸。
9. 关闭模拟触摸，检查原有鼠标移动、Alt 点击／拖动／滚轮、N 建造开关和 Tab 返回玩家。
10. 通过 `Tools → Darwin's Farm → Input → Check touch gesture rules` 运行手势回归检查。

Device Simulator 可检查单指触摸；双指手势已在运行中的 Input System 中通过事件注入检查，后续还需 Android 真机验证。当前没有将编辑器模拟视为真机验收。

已通过编译、手势规则回归，以及 14 项运行接入检查：触控松手移动、长按地块、点击种群、真实 uGUI 连续拖动、单指平移、双指缩放及松手抑制、后台中断清理、鼠标恢复、电脑 Alt 点击／拖动／滚轮、N 建造、Tab 返回玩家、Inspector 鼠标模拟触摸。
