# 生物能经济系统：当前讨论稿

以下是本轮确定的收入公式与试填价格，尚未接入代码。单位为生物能，`ln` 为自然对数。具体物种价值及未列出的工程费用仍待配置或讨论。生物能与动物摄食能量、植物库存分开记账。

## 收入

| 来源 | 规则 | 结算口径 |
|---|---|---|
| 每日收成 | `Σ_s ⌊V_s × ln(N_s)⌋` | 每个模拟日按物种汇总全图野外存活个体数 `N_s`，每种结算一次。`N_s = 0` 时收入为 0；生态仓个体不计入。 |
| 种群收割 | 一次移除选中种群的 50% 或 50 只，取大者；收益 `⌊10 × V_s × ln(H)⌋` | `H` 为实际收割数量。人数不足 50 时最多收割现有人数，不能凭空获得个体；`H ≤ 1` 时收益为 0。捕获后真实减少该种群人数。 |
| 解锁奖励 | 植食者 200；一级捕食者 500；二级捕食者 1,000 | 每个物种首次解锁发一次；初始已拥有的物种是否发奖仍待确定。灭绝后重现或迁移不重复发奖。 |

`V_s` 是**每个物种各自配置**的价值，不由营养级唯一决定。首轮配值参考为植食者约 10、一级捕食者约 20、二级捕食者约 40；同一营养级的不同物种可以高低不同。建议字段放在 `SpeciesData`，由存档保存发奖状态。

收割数量的可执行口径暂写为 `H = min(N_p, max(ceil(N_p / 2), 50))`，其中 `N_p` 是选中种群的操作前人数。例：30 只收 30 只，80 只收 50 只，120 只收 60 只。`ceil` 只用于解决奇数种群的半只取整问题，不改变“50% 或 50 只取大者”的本意。操作前应显示收割后人数与灭绝风险。

例如某物种 `V_s = 10`，全图野外共 100 只，日收入为 `⌊10 ln(100)⌋ = 46`。若这 100 只属于同一种群，收割 50 只，收益 `⌊10 × 10 × ln(50)⌋ = 391`；剩余 50 只在没有其他同物种个体时，次日日收入为 39。

## 支出：地块、种群与设施

| 支出类别 | 对应科技 / 玩家动作 | 当前价格 | 作用与边界 |
|---|---|---:|---|
| 扩张地块 | 地块构筑器（暂名） | 600 / 格 | 在合法相邻位置放置预设地块；新地块带预设环境与植物，不自动附赠动物。当前对各地块类型统一定价。 |
| 改变水道形状或旋转 | 水道重塑器（暂名） | 500 / 次 | **初始放置时选择旋转免费**；建成后改变形状或旋转收费，并预览水域、路线及种群后果。 |
| 拆除地块 | 地块拆解器（暂名） | 200 / 格 | 拆除规则仍按策划案建议：非初始、无种群、无生态仓；是否允许拆断关键通路待确认。 |
| 手动迁移 | 活体迁运舱（暂名） | 1,000 / 次 | **完整种群整体搬迁**到一个合法目标地；源地不留该种群，也不复制个体。旧测试器的「至多迁出 100 只」不适用于此玩家操作。 |
| 定向进化 | 定向基因编辑器（暂名） | **1,000 / 次** | 直接修改**选中种群**的两项特征。陆地及非海洋种群从适温、适湿、运动、繁殖、体型中任选两项；海洋种群从运动、繁殖、体型中任选两项。每项选择 `+25 / −25 / +50 / −50`，组合不影响价格；按各字段合法边界裁剪。 |
| 生态仓建造 | 生态仓 | 5,000 / 栏位 | 复制一个现存种群，仓内固定保留 50 只备份；即使来源不足 50 只也允许复制，不减少原野外种群。备份继承复制时的种群性状，暂停性状变化等生命活动，不产常规收入。 |
| 生态仓释放 | 复育释放舱（暂名） | **0（免费）** | 仓内 50 只可随时一次性迁入**任意合法地块**，无需与原地相邻；释放后备份直接耗尽。目标地已有同物种时合并，释放后的个体重新参与正常生态模拟。 |
| 生态仓维护 | 生态仓维生模块（暂名） | **0（免费）** | 不收每日维护费。 |

陆地与含水状态转换、水域重组附加费用等尚未在本轮定价，不沿用上一版试填的 1,500 和重组公式。植被背景收入也未列入本轮收入表，暂不计入已定经济规则。

同物种合并沿用现有迁徙规则：数量相加，性状按个体数加权平均。仍需在实现前明确生态仓「合法地块」的判定阈值（仅生态位与空间，还是也要求当前气候、食物能支持存活），以及种群性状在边界裁剪后没有实际变化时是否仍收费。定向进化修改的是选中种群的当前性状，不修改 `SpeciesData` 模板，也不直接解锁新物种或跳过进化网。

策划案 V4 已提出下列科技名称，最终名称和造型仍可调整。科技只产生表中的环境效果，不附加未确认的遮阳减产、地热改湿度或施工耗时。

| 外星科技 | 具体作用 | 当前价格 | 生效时间 |

水域的植物库存、每日增量和海拔按整个水域操作，温湿度工具不能用于水格。此表暂将对应外星科技的标价作为操作基础价；若整域需要按面积加价，应另行确定，不沿用上一版每格附加费。季风覆盖重叠导致自动取消时，仍按实际支付金额 100% 退款，退款按凭据和季风 ID 幂等处理。

## 实现提示

当前 `SimulationInterventionController` 只校验目标和数值，不扣费；编辑器实时模拟器是开发测试入口。正式玩家操作需要统一预览、校验余额、原子提交生态变化与扣费。每日收入只结算一次；收割必须同时减少种群和增加余额；解锁奖励必须跨存档防重复。上述收入与价格是策划规则，尚未宣称运行时已实现。
