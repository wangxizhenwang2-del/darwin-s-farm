# Task12 v0.5 — 四边形地块／五种共存／四次进化／可撤销操作

**只需给 Agent 一个 ZIP 和一段提示词。** 本包供 Agent 在已有 Unity 工程中执行最长4小时的自主诊断、建模、最小修复和真实集成验收。

**优先按顺序阅读**：
1. `RULES_V05_CANONICAL.md` — **权威玩法规则**，明确四边形共享边、五种共存与四次进化、十按钮、随时撤销、正式进化10%、迁徙测试不强求20次。
2. `MODEL_FORMULAS_V05.md` — 当前 Unity 旧源码可审计的计算公式、冻结原则及待验证实验公式，防止混用不同时代的数字。
3. `AGENT_PROMPT.md` — 四小时计划、固定种子、对照实验、测试矩阵与封包约束。
4. `BASELINE_EVIDENCE.md` — 上轮历史验收边界（只能作为基线，不能当新任务结果）。
5. `evidence/` — 两份旧验收与诊断压缩包，含早期 Agent 提示词；其中与本版冲突者**全部失效**。
6. `reference_code/` — 从验收差异中重建出的只读 LandLifeRules/LandRuleTuning/V048ScenarioReplay 参考文件，**不是应直接覆盖项目的源码**。

## 本版明确更正

- **地块：四边形，不是六边形；**按真实共享边与 neighbors 图做邻接。
- **规模：先2–4地块机制测试**；综合地图按必要生态位确定，不设7块下限。
- **迁徙：2次真实综合事件 + 合并/拒绝的单项测试**，不要硬凑20次。
- **5种共存=鸡、彩鸡、孔雀、灵感菇狸、鹿；4次正式进化**，不是5个进化目标。
- **所有持续环境操作可撤销**；恢复期结束后才开始严格自然稳态观察；存量事务的逆操作不等于时光倒流。
- 新版正式进化10%无100只上限，须与旧代码普通 `splitFounderFraction=0.05` 分开对待。

ZIP **不包含完整 Unity 工程**，需要在有源项目的 Agent 工作区运行；否则仅做资料级分析，不得假称 Unity PASS。
