# 地块状态 UI 验收

已接入 `Assets/Scenes/WhiteBox.unity`。在 Unity 中打开场景，进入 Play，选择「新游戏」，关闭首次物种发现卡片后验收。

| 操作 | 预期结果 |
| --- | --- |
| 使用默认视角或适当放大，把地块移到画面中心 | 无须点选，地块上方自动显示植物库存条。默认透视相机视野角 ≤ 60° 时出现，> 66° 时隐藏。 |
| 拉远镜头，或将地图移出画面中心 | 状态面板隐藏。 |
| 建造相邻地块，按住鼠标中键平移地图 | 面板切换到新的中心地块，同一时间只有一套；两块地距离几乎相等时保持稳定。 |
| 使用「植物存量」工具改变地块库存 | 库存条和数值同步变化；填充比例等于当前植物库存 / 容量上限。库存指生物量。 |
| 给同一地块投放「温度降低一档」和「湿度提高一档」，然后关闭工具操作面板 | 库存条上方并排显示两个实际生效的工具，各自显示阶段与剩余天数。关闭操作面板后图标继续显示。 |
| 等待工具从「生效」进入「维持」 | 陆地工具通常先经历 25 天生效阶段，再维持 150 天；维持剩余 75 天时，清晰的灰色扇形覆盖图标圆面的一半，剩余时间越少覆盖越多。 |
| 按空格暂停，稍等后再继续；按 4 切到 4 倍速 | 暂停时天数和遮罩不变；加速后随游戏天数更快推进。1 倍速通常每秒 1 天。 |
| 撤销其中一个工具，或等待维持时间结束 | 对应图标变灰，显示「恢复」及剩余天数；恢复结束后该图标消失，另一个工具独立计时。 |
| 在工具维持阶段，通过游戏菜单保存并读取存档，再放大并居中该地块 | 植物库存、工具类型和增减档位、剩余天数、遮罩比例与保存时一致。 |
| 在状态面板所在区域滚动缩放、拖动地图或点选地块 | 状态 UI 不拦截地图操作。 |

补充：植物存量、海拔属于即时操作，没有持续倒计时。水域植物增量效果采用现有的 50 天维持时长。一个工具恢复期间可能与其他工具并存，各自显示状态。

## 可调参数

选择场景中的 `Canvas`，在 `TileStatusPresenter` 组件调整：

- `Show Field Of View` / `Hide Field Of View`：透视相机的显示、隐藏门槛，默认 60 / 66。
- `Show Orthographic Size` / `Hide Orthographic Size`：正交相机的显示、隐藏门槛，默认 40 / 45。
- `Center Radius`：中心显示范围，单位为相机视口高度比例，默认 0.4。
- `Switch Margin` / `Switch Delay`：切换地块的距离缓冲和等待时间，默认 0.025 / 0.15 秒。
- `Screen Offset`：相对于地块投影点的 UI 偏移，默认向上 26 个 Canvas 单位。

`Canvas/TileStatus` 中可调整工具卡片、库存条、文字和配色。

## 自动检查

停止 Play 后，执行菜单 `Tools > Darwin Farm > UI > Check Tile Status Timelines`。Console 出现 `TILE_STATUS_TIMELINES_PASS` 表示生效、维持、半程、恢复、到期、撤销、陆地/水域时长与序列化检查通过。

完整运行检查覆盖 24 项，包括独立圆形遮罩、放宽后的显示范围、真实磁盘存档和场景重载。先重新进入 WhiteBox 的 Play 模式，再从项目目录运行：

```powershell
unity command set_autotick --caller plugin --skill unity-cli
unity command run_script --caller plugin --skill unity-cli -- --file 'Tools/TileStatusAudit/RuntimeAudit.cs' --timeout_ms 45000
```

输出 `TILE_STATUS_RUNTIME_PASS: 24 checks` 表示通过。检查使用临时存档目录，完成后可退出 Play。
