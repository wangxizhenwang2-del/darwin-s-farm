# V4.4 生物能经济系统

`BioenergyAccount` 是唯一余额与收据账本。场景中的 `MapSimulationBridge` 在运行时为地图对象装配账户、玩家操作控制器和白盒操作面板。正式界面应调用 `PlayerEconomyController`、`EnvironmentTechnologyController`，只读取预览，不直接改地图、种群或余额。

## 填数值

在 Unity 菜单 **Darwin's Farm → 经济系统数值** 打开编辑窗口。窗口直接编辑 `Assets/Resources/BioenergySettings.asset` 中的开局余额、收入和收割系数、首次解锁奖励、地图与种群操作费用、环境科技费用以及无物种资产种群的备用价值；物种价值栏直接编辑各 `SpeciesData` 资产的 `bioenergyValue`。修改自动保存。新增物种后点击“刷新物种列表”。费用与收益在下一次计算时采用新值；开局余额在新开局时采用新值。经济限制开关仍在游戏内经营面板，关闭后各项费用实际支付为零。

## 已接入规则

- 初始余额 2,000。`CostsEnabled` 为经济限制开关；关闭时合法操作照常执行，但实际支付额为 0。收入和奖励仍照常获得。
- 每日收入：每种野外物种计算 `floor(V × ln(N))`，再求和；`N ≤ 1` 收入 0。仓内备份不计。初始物种不领取首次解锁奖。后续首次出现按营养级领取 200／500／1,000，账户按模拟日去重。
- V4.6 的 15 种正式物种价值读取 `Assets/BiowebV46/Species`，范围 1～30，各物种有稳定 `economyId`。无物种资产的旧动态种群仍按营养级 10／20／40 取备用值。
- 扩张 600、改水道形状或旋转 500、拆除 200、整群迁移 1,000、定向进化 1,000、生态仓建造和首次复制 5,000。释放免费。拆除拒绝初始格、有种群格、河岸被占用格，以及会切断地图的格。定向进化两项都被边界裁剪到不变时拒绝且不扣费。
- 温湿度 ±25／±50 分别 220／480；植物高档 260／560，低档 420／960；海拔 ±1 为 500；季风为 1,000。价格按每次操作计，整片水域不另收每格费用。主动撤销不退款；季风因覆盖重叠被取消时，按实际支付凭据退还，零支付的季风退款也是零。
- 收割人数 `min(N, max(ceil(N/2), 50))`，收入 `floor(10 × V × ln(H))`，`H ≤ 1` 收入 0。提交同时减少种群。生态仓保存 50 只、不减少来源，释放后仓位消失。

## 接口与存档

`BioenergyAccount.CaptureState/TryRestoreState` 保存余额、开关、结算日、首次奖励标记和交易收据。`PlayerEconomyController.CaptureStorageState/TryRestoreStorageState` 保存生态仓备份。加载顺序：先恢复地图、物种图与模拟日，再恢复账户和生态仓，最后恢复环境时间线和待结算退款；在下一模拟日前完成。仓库当前没有完整世界存档系统，这两个接口用于与其后续对接，不能单独作为完整游戏存档。

正式玩家的地图放置入口已改由 `PlayerEconomyController.TryExpand` 提交。WhiteBox 地块面板增加横向、弯曲、三叉与湖泊四种水格预设，初次放置的旋转免费。场景中的科技面板会显示余额、预估日收和费用；经营面板提供经济限制开关、收割、仓库、迁移、进化、拆除与水道改造操作。编辑器审计以及旧的 `SimulationInterventionController` 仍是开发测试入口，可直接调用底层环境模型，不属于正式玩家付费通道。
