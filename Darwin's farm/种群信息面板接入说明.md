## 新增物种资料的配置流程

1. Project → Create → Darwin's Farm → Species，或选择现有 SpeciesData 资产。
2. 填写 Species Name。
3. Species ID 自动生成；可以改成项目统一的唯一标识。复制资产后请修改 ID，重复时 Console 会警告。
4. 将图片拖入 **Portrait**。它只影响信息面板；原有 **Sprite** 继续用于场景种群形象。Portrait 为空时优先使用 Sprite，两者都为空时显示带问号的占位区域。
5. 在 **Description** 填写中文简介。空白显示“暂无物种介绍”；长简介可用滚轮查看。
6. 让具体 `PopulationData.species` 引用该资产。现有种群创建/生态网络仍由现有系统管理。

**新增物种的资料展示无需修改任何种群 UI 代码。** 若希望新物种参与自动进化、捕食或初始生成，还需按原生态系统配置其演化/猎物关系及生成入口；这些不由 UI 自动创建。

同物种的多个种群共享 SpeciesData 的头像与简介；数量、属性、种群 ID、出生死亡和地块读取各自 PopulationData。物种 ID 不替代 PopulationId，也未改变原迁徙合并身份规则。

## 雷达图字段

| 显示 | 真实字段 | 图形范围 |
| --- | --- | --- |
| 适温 | fitTemperature | 0～100 |
| 适湿 | fitHumidity | 0～100 |
| 运动 | movementAbility | 0～100 |
| 繁殖 | fertility | 0～100 |
| 体型 | size | 1～100（图形以 0～100 映射） |

适温/适湿表示种群偏好的环境值，并非“越高越强”。图形归一化和钳制只影响绘制；标签保留真实值。综合适应度保留在可滚动辅助区。图表的颜色、最大值、线宽和标签位置可在组件 Inspector 查看/调整，内容使用乐米小奶泡体。

绿色填充表示当前 PopulationData 属性；红色虚线表示该种群当前所属 SpeciesData 的基础属性，按同一顺序读取 baseFitTemperature、baseFitHumidity、baseMovementAbility、baseFertility、baseSize。基线不是打开面板时临时截取的种群属性，也不是每个种群出生时的独立快照。缺少 SpeciesData 时隐藏红色虚线，不伪造基准。虚线颜色、线宽、段长及间隙可在 PopulationRadarChart Inspector 调整，不影响模拟计算或实际运动体积。

## 食物关系与占位

图示范围是**当前地块的陆地群落**。读取当前 BlockInfo.community，调用原 FoodWeb.CanEat；该规则优先读取 SpeciesData.preySpecies，并保留原营养级回退规则。食草种群的来源显示植物；本地缺少食物/捕食者时显示“当前无食物源/当前无捕食者”，不代表全地图或配置网络中绝无该关系。列表过长可滚动。

水域/空中关系图暂标“生态关系待接入”，未伪装成已接通的陆地食物关系。缺生态数据的白盒测试种群显示未接入。

模型中没有可用于显示“运动 +20”的完整变异历史，所以变异显示“暂无记录”。未把当前运动值或变异小数累积量当成增量。没有使用出生减死亡来冒充包括迁徙/进化的总数量趋势。数量直接读取实际种群数量。

## 刷新及交互

GameInformationUI 原有事件和 0.25 秒刷新仍负责更新面板。刷新修改既有对象的文本、图片和网格，不重新生成整套对象。保留一个种群窗口限制、Alt 点击、松开 Alt 保持、文字拖拽、置顶、关闭与滑入动画。普通 TMP 文本挂载原 InformationTextDragHandle；长内容使用滚轮滚动，文字拖动仍移动窗口。

简介和辅助信息均采用 ScrollRect → Viewport（RectMask2D）→ Content（TMP），内容高度按真实文本计算，没有 LayoutGroup/ContentSizeFitter 相互争抢尺寸。

## 核查与验收

已完成：Unity 编译；Play Mode 帧推进；实际鸡种群资料与截图排版检查；雷达绘制网格验证；用独立测试数据检查同种群资料、同物种不同 ID/数量/属性、切换鹿和缺资料回退；使用独立临时群落验证鸡→狸猫捕食关系与原配置一致；调用 X 按钮验证关闭和解除鼠标遮挡；长简介滚轮测试（内容高度 1436.2、视口高度 207、滚动位移 72）；模拟指针事件验证窗口移动（-40、20）。

测试数据只传给 UI 或独立临时对象，没有覆盖实际种群的计算结果。交互事件检查不能替代完整人工游玩验收；Alt 鼠标选择、摄像机拖动、N 建造和多分辨率实际操作仍建议按下表人工复核。

1. 运行 Whitebox，Alt+左键点击鸡：头像、简介、数量、雷达图直接可见，松开 Alt 保持显示。
2. 点击文字拖动面板：只移动窗口；点击 X 后重新选择另一种群。
3. 同物种不同种群共享图片/简介，辅助区 ID、数量及属性随目标变化。
4. 给另一物种填写 Portrait/Description 后选择它：自动换图、换简介，UI 不需改代码。
5. 在简介和辅助区域滚轮浏览长文本，确认 ID 可以完整查看且内容不越过纸面。
6. 查看本地捕食者/猎物：与本地群落及 preySpecies 配置一致。
7. 同时打开地块窗口，检查重叠置顶、动画、UI 不穿透；复核 Alt 拖地图、滚轮缩放和 N 建造。

场景与脚本引用已自动集成，不需手动挂新组件。需要你补充的资料仅为尚未填写的其他物种简介，以及未来想使用的专用头像。
