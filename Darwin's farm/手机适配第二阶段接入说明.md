# 手机适配第二阶段：可编辑 UI 与建造、科技操作

## 本阶段实现的效果

Android 手机横屏使用独立的手机 Canvas。电脑继续使用原来的 HUD、两类信息窗口和建造操作。手机展示层读取原有地图、生态、时间和趋势记录，不创建第二套模拟、历史记录或导航系统。

- 顶部提供时间、暂停／继续、1X／2X、定位玩家、进入／退出建造。
- 环境信息和生物信息使用同一个可移动信息栏的两个页签，各自保留选中的目标。关闭只解除当前页签对应的目标；同类目标仍不能自动替换。
- 正文上下滑动，标题拖动整个窗口；窗口被限制在安全区域内。窗口沿用原来的滑入／淡出动画。
- 环境页显示真实趋势图、地块详情和可展开的地块科技。生物页复用物种资料、数量、变异、雷达图、初始数值红色虚线及食物关系。
- 建造列表可以横向滑动。点击一种地块后，地图上的轻点只定位预览；可旋转 90°、确认或取消，松手不会自动放置。
- 预览仍包含现有地形起伏和装饰。移动／缩放相机不会改变已定位的预览网格坐标。
- 科技类型、档位、真实效果预览、投放和撤销调用已有 `EnvironmentTechnologyController`，继续遵守水域、海拔档位和恢复阶段等原有规则。
- 手机显示时收起浮在地图上的白盒测试工具；电脑模式仍显示原工具。Editor 的种群数值模拟器不受影响。

**新增按钮、提示、页签和操作区均以文字说明功能。所有 UI 对象已写入 WhiteBox 场景，不需要进入 Play Mode 才能出现在 Hierarchy。**

经济数据尚未接入，显示“生物能：未接入”；科技费用显示来自现有控制器的 0，并标明经济未接入。

## 在非 Play Mode 下编辑

1. 打开 `Assets/Scenes/WhiteBox.unity`。
2. Hierarchy 选中 **MobileUICanvas**。
3. Inspector 的 **Mobile Game UI → Display Mode** 改为 **Mobile**，即可预览手机 UI。默认 **Auto** 保留正常电脑操作，Android 运行时会自动选择手机界面。
4. 用 **Information Tab** 切换 Environment／Population，编辑对应正文。退出 Play Mode 后对象和引用仍保留。
5. 完成编辑后把 Display Mode 恢复为 **Auto** 并保存场景。

编辑模式会显示建造列表和预览操作区，方便替换美术；实际运行时只在相应建造／预览状态显示。

### 替换图片与字体

- 按钮／面板底图：选中对象，在 **Image → Source Image** 放入美术 Sprite。保留 Button、Graphic Raycaster、ScrollRect、拖拽组件及控制器引用。
- 按钮文字：子对象 **FunctionLabel → TextMeshProUGUI** 调字号、颜色、对齐等。统一沿用现有乐米小奶泡体；地块详情与趋势图沿用已有文字组件。
- 图像位置：修改相应子对象的 RectTransform；不要通过移动 SafeArea 调整单张图片。
- HorizontalLayoutGroup 管理的按钮宽度：调整按钮 **Layout Element → Preferred Width／Min Width**。这些对象的 Pos X 由布局组管理。
- 科技选中颜色：`TechnologySection → Mobile Technology Panel → Selected Color／Normal Color`，类型和档位使用同一高亮规则。
- 科技区在编辑时展开：勾选 Mobile Technology Panel 的 **Expanded**，在组件菜单执行 **Refresh technology preview layout**。这一操作只调整展开布局。
- 物种图片、名称、数量、时间、效果预览等文字和 Sprite 在运行时绑定真实数据，Inspector 中的示例内容会被数据替换；字体、底图和内部排版可保留。

### 布局参数

| Mobile Game UI 参数 | 用途 |
| --- | --- |
| Display Mode | Auto 自动选择；Desktop／Mobile 可强制预览 |
| Information Tab | 编辑时切换环境／生物正文 |
| Maximum Drawer Width | 信息栏最大宽度，默认 520 Canvas 单位 |
| Drawer Width Fraction | 信息栏占安全区宽度的比例，默认 0.43 |
| Drawer Default Position | 右上角默认位置，默认 (-8, -92) |
| Drawer Bottom Clearance | 信息栏底部为建造操作预留的空间，默认 152 |
| Refresh Seconds | HUD 和信息数据刷新间隔，默认 0.25 秒 |
| Editor Safe Insets | 仅 Editor 使用，依次为左、上、右、下；按 720 高度 Canvas 单位模拟刘海和系统手势区域 |

真实手机直接使用 `Screen.safeArea`；Editor Safe Insets 不进入设备布局计算。窗口位置、外框尺寸和安全区由控制器响应屏幕变化，内部图片与文字在 Hierarchy 编辑。

## 手动验收

### 手机界面

1. Play Mode 将 MobileUICanvas 的 Display Mode 设为 **Mobile**，鼠标自动模拟单指触摸。Game 窗口保持焦点。
2. 轻点地面松手后玩家移动；单指拖地图、长按地块、轻点种群延续第一阶段手势。
3. 环境、生物都打开后切换页签；关闭当前页签应只解除这一类目标，另一类继续保留。
4. 从趋势图或详情正文滑动：只滚正文；从标题拖动：只移动窗口，地图不移动。拖到屏幕边缘后标题和关闭按钮仍可访问。
5. 暂停／继续、1X／2X 使用原时间控制；定位玩家调用原相机返回入口。
6. 切换 16:9、20:9、21:9 横屏；Editor Safe Insets 可试 (72,16,32,24)，观察顶部按钮与窗口均在安全区域内。测试后将其恢复为 0。

### 建造与科技

1. 点击“建造地块”，左右滑动列表：只滚动，不生成预览。
2. 轻点一个地块按钮；预览先等待地图定位。轻点空的相邻网格并松手，应显示地形和装饰预览，尚未创建实际地块。
3. 按旋转；树木／地形预览方向随 90° 步进变化。平移／缩放地图，预览保持原网格位置。
4. 点击确认：实际地块只创建一次，旋转与预览一致，沿用原过渡地表、障碍及 NavMesh 更新。已占用位置不可确认。
5. 点击取消：只移除预览；已确认的地块保留。退出建造解除预览并恢复玩家输入。
6. 长按地块 → 环境页下滑 → 展开科技；切换类型／档位观察高亮与真实预览，投放后“当前科技”应变化。
7. 撤销仍按原科技规则执行；海拔不提供 ±2 档，恢复阶段不可重复撤销。手机 UI 不额外绕过水域规则。

### 常驻与电脑回归

1. 退出 Play Mode：MobileUICanvas 和上述所有子对象仍在 Hierarchy；更换底图、字号、子对象位置并保存后，再运行检查这些设置保留。
2. Display Mode 恢复 **Auto**，Main Camera 的 Simulate Touch With Mouse 保持关闭。电脑继续使用原信息窗和建造 UI；N 开关建造、Alt 点击／拖动／缩放、Tab 返回玩家延续原控制器。
3. 不需要手动挂脚本或补引用，WhiteBox 场景已完成接入。其他场景若尚未拥有原信息／建造系统，不能直接复制一个未绑定的手机 Canvas 当作完整接入。

## 实际验证与后续范围

已通过 Unity 编译；在运行中的场景通过 Input System 事件注入检查了正文滚动、标题拖动、地图输入不穿透、建造列表滑动不误选、点击选择与地图定位、持久预览、90° 旋转、确认建造及 NavMesh 更新、占用位置拒绝、取消预览、两类目标独立占用与关闭、重新打开从顶部显示、电脑／手机视图恢复与电脑 N 键。HUD 和科技按钮通过实际场景中的 UnityEvent 检查了原控制器状态。

检查了 16:9／20:9／21:9 横屏以及模拟安全区，并实际查看了环境、种群和科技页截图；保存场景时确认没有删除原有场景对象。非 Play Mode 的 UI 页签编辑和常驻对象也进行了检查。

本阶段没有制作 APK 或进行 Android 真机验收。真实设备的触摸精度、双指体验、刘海／系统导航栏、字体和渲染性能、后台恢复、Android 横屏构建与安装属于下一阶段。经济逻辑继续标记为未接入。

## 信息页显示补充

- 手机正文是滚动窗口，打开时显示顶部；向上滑动正文或拖动右侧滚动条，可查看完整雷达图、食物关系与下方详情。
- 物种介绍不需要内部滚动时，手势交给整页；较长介绍保留内部滚动，到达边缘后的下一次滑动可交给整页。鼠标滚轮也可以滚动正文。
- 环境页和生物页分别引用 PC 端同一份背景 Sprite。背景与滚动条已保存在非 Play Mode 的 Hierarchy 中。
- 背景对象：`MobileUICanvas/SafeArea/InformationDrawer/InformationBackground`；两类图片绑定在 Mobile Game UI 的 `Environment Background`／`Population Background`。
- 滚动条对象：`InformationDrawer/InformationScroll/VerticalScrollbar`。滚动正文不会移动地图或窗口，标题仍负责拖动窗口。
