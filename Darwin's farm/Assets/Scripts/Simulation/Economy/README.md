# 生物能经济系统：当前讨论稿

以下是本轮确定的收入公式与试填价格，尚未接入代码。单位为生物能，`ln` 为自然对数。每个物种的具体价值仍需配置；生物能与动物摄食能量、植物库存分开记账。初始余额为 **2,000**，初始赠送物种不领取解锁奖励。

## 收入

| 来源 | 规则 | 结算口径 |
|---|---|---|
| 每日收成 | `Σ_s ⌊V_s × ln(N_s)⌋` | 每个模拟日按物种汇总全图野外存活个体数 `N_s`，每种结算一次。`N_s = 0` 时收入为 0；生态仓个体不计入。 |
| 种群收割 | 一次移除选中种群的 50% 或 50 只，取大者；收益 `⌊10 × V_s × ln(H)⌋` | `H` 为实际收割数量。人数不足 50 时最多收割现有人数，不能凭空获得个体；`H ≤ 1` 时收益为 0。捕获后真实减少该种群人数。 |
| 解锁奖励 | 植食者 200；一级捕食者 500；二级捕食者 1,000 | 每个物种首次解锁发一次；**初始赠送物种不发奖**。灭绝后重现或迁移不重复发奖。 |

`V_s` 是**每个物种各自配置的 10～100 价值**，不由营养级唯一决定。首轮配值参考为植食者约 10、一级捕食者约 20、二级捕食者约 40；同一营养级的不同物种可以高低不同。建议字段放在 `SpeciesData`，由存档保存发奖状态。

收割数量的可执行口径暂写为 `H = min(N_p, max(ceil(N_p / 2), 50))`，其中 `N_p` 是选中种群的操作前人数。例：30 只收 30 只，80 只收 50 只，120 只收 60 只。`ceil` 只用于解决奇数种群的半只取整问题，不改变“50% 或 50 只取大者”的本意。操作前应显示收割后人数与灭绝风险。

例如某物种 `V_s = 10`，全图野外共 100 只，日收入为 `⌊10 ln(100)⌋ = 46`。若这 100 只属于同一种群，收割 50 只，收益 `⌊10 × 10 × ln(50)⌋ = 391`；剩余 50 只在没有其他同物种个体时，次日日收入为 39。

## 支出：地块、种群与设施

| 支出类别 | 对应科技 / 玩家动作 | 当前价格 | 作用与边界 |
|---|---|---:|---|
| 扩张地块 | 地块构筑器（暂名） | 600 / 格 | 在合法相邻位置放置预设地块；新地块带预设环境与植物，不自动附赠动物。当前对各地块类型统一定价。 |
| 改变水道形状或旋转 | 水道重塑器（暂名） | 500 / 次 | **初始放置时选择旋转免费**；建成后改变形状或旋转收费，并预览水域、路线及种群后果。 |
| 拆除地块 | 地块拆解器（暂名） | 200 / 格 | 仅对可拆除的非初始、无种群地块执行；生态仓不占真实地块，不参与这项判定。是否允许拆断关键通路待确认。 |
| 手动迁移 | 活体迁运舱（暂名） | 1,000 / 次 | **完整种群整体搬迁**到一个合法目标地；源地不留该种群，也不复制个体。旧测试器的「至多迁出 100 只」不适用于此玩家操作。 |
| 定向进化 | 定向基因编辑器（暂名） | **1,000 / 次** | 直接修改**选中种群**的两项特征。陆地及非海洋种群从适温、适湿、运动、繁殖、体型中任选两项；海洋种群从运动、繁殖、体型中任选两项。每项选择 `+25 / −25 / +50 / −50`，组合不影响价格；按各字段合法边界裁剪。 |
| 生态仓建造及首次复制 | 生态仓 | 5,000 / 栏位 | 生态仓位**不建在真实地块上**。建造时复制一个现存种群，仓内仅保存**一个种群、50 只**备份，可无限期存放；即使来源不足 50 只也允许复制，不减少原野外种群。备份继承复制时性状，不繁殖，暂停其他生命活动，不产常规收入。每个仓位只可复制一次。 |
| 生态仓释放 | 复育释放舱（暂名） | **0（免费）** | 仓内 50 只可随时一次性迁入**任意合法地块**；释放后备份和仓位同时消失，不能再次复制。若要保存下一份备份，须新建仓位并支付 5,000。目标地已有同物种时合并，释放后的个体重新参与正常生态模拟。 |
| 生态仓维护 | 生态仓维生模块（暂名） | **0（免费）** | 不收每日维护费。 |

**不提供直接改变已有地块陆/水基础状态的玩家操作**；玩家若要更换，须先符合拆除条件，再按 200 拆除、600 重新扩张。水道形状或旋转仍按每次 500 计价；V4 允许由此触发的水域重组保留当时植物增量，作为已接受的经营路径。植被背景收入未列入本轮收入表，不计入新经济规则。所有野外动物灭绝且没有生态仓备份时，允许失败并重新开局，不提供凭空恢复物种的保底途径。

同物种合并沿用现有迁徙规则：数量相加，性状按个体数加权平均。手动迁移与生态仓释放的合法目标以 V4.3 的生态位和天空槽位规则为准；食物、气候与容量不阻止提交。种群性状在边界裁剪后没有实际变化时是否仍收费，需在经济系统接入前定稿。定向进化修改选中种群的当前性状，不修改 `SpeciesData` 模板，也不直接解锁新物种或跳过进化网；性状立即变化，但不额外给予有效日或分化抽取，正常分化每天检查。

**数值观察：**一次性仓位消除了空仓反复复制的即时获利循环。即使 `V_s=100`，单独释放并立即收割 50 只的收益也只有 `⌊10×100×ln(50)⌋=3,912`，低于新仓成本 5,000；若复制体在野外存活，它仍能增加后续日收入，回本速度需要实测。

**同日顺序：**玩家在推进日之前提交的所有操作（地块工程、环境科技、手动迁移、定向进化、收割、生态仓建造与释放）按实际提交顺序逐笔生效。推进日时先抽取并原子结算事件，再推进环境、植物、摄食、生死、性状、分化、自然迁徙；之后更新新物种解锁和首次奖励、结算一次日收入，最后判定失败。暂停不推进日结算。

## 支出：外星环境科技

策划案 V4.3 定义十项科技，名称和造型仍可调整。下表价格是未来经济系统的试填值；**当前测试 UI 投放与撤销费用均为 0**。科技只产生表中的环境效果，不附加遮阳减产、地热改湿度或施工耗时。

| 外星科技 | 具体作用 | 当前价格 | 生效时间 |
|---|---|---:|---|
| 热通量注入阵列 | 单格增温 `+25 / +50` | 220 / 480 | 25 天进入、100 天维持、25 天退出。 |
| 辐射散热幕 | 单格降温 `−25 / −50` | 220 / 480 | 同上。 |
| 云核播撒器 | 单格增湿 `+25 / +50` | 220 / 480 | 同上。 |
| 水汽回收阵列 | 单格降湿 `−25 / −50` | 220 / 480 | 同上。 |
| 生长催化脉冲 | 每日植被增量 `R +25,000 / +50,000` | 300 / 680 | 立即生效，100 天恢复；不直接补库存。 |
| 生态播种舱 | 按容量增加植物库存 `S +25%B / +50%B` | 260 / 560 | 一次性投放，结果不超过容量 `B`；**不同于保存动物的生态仓**。 |
| 生态抑制装置 | 当时实际 `R` 与 `S` 同时减少 25% / 50% | 420 / 960 | 原子提交；`R` 100 天恢复，`S` 的损失不回滚。取代独立减产、回收科技。 |
| 地壳抬升器 | 海拔 `+1` | 500 | 瞬时生效；重算地形和连接关系。 |
| 地层沉降器 | 海拔 `−1` | 500 | 同上；超出海拔 0～2 时拒绝。 |
| 季风锚 | 相连区域长期改变温度与湿度 | 1,000 / 次 | 25 天进入、永久维持；强度两项分别选 `±20 / ±40`。 |

水域的植物库存、每格每日增量和海拔按同高且开口相对的整个连通水域操作，温湿度工具不能用于水格。水域每格容量为 1,500,000，默认日增量和初始库存均为 75,000；整域操作不另加每格费用。季风从海拔 0/1 的陆格出发，可桥接恰好一个同高水格，但水格不受温湿度效果。经济系统接入后，重叠取消才按实际支付额 100% 退款；当前投放费用为 0，因此没有退款收益。

## 实现提示

当前 `EnvironmentTechnologyController` 已提供十项科技的预览、目标校验、零费用投放与可撤销时间线；地块上方的白盒面板是测试 UI。经济系统仍未接入，正式玩家操作还需统一余额校验与扣费。每日收入只结算一次；收割必须同时减少种群和增加余额；解锁奖励必须跨存档防重复。上述收入与价格是策划规则，尚未宣称运行时已实现。
