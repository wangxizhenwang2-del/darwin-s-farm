# 定向变异回归记录

日期：2026-10-03。逐场景结果见 [directed-results.txt](directed-results.txt)。运行 `dotnet run --project Tools/SimulationAudit/MutationAudit.csproj` 可复现代码层测试。

## 当前规则

- 玩家改变温度、湿度或植物每日恢复量并点击应用后，下一模拟日立即评估一次变异；随后按变异间隔继续。新模拟器默认间隔 7 天、步长 2。已有编辑器窗口若保存了旧输入值，需手动调整。
- 温湿度失配先选幅度最大的一项。环境已基本适宜时，比较捕食关系中的速度和体型差、相邻食性的可持续可得能量、以及一个变异周期内的数量趋势。每个种群每周期最多改变一个性状；无足够压力则不变。
- 运动或体型增加要求当天摄食基本充足，并用 `K/当前数量` 检查增加后的持续能耗。明显占优且缺食时才降低。体型无初始值百分比限制，最低为 1。
- 捕食收益使用捕食者与猎物已有的运动和体型差修正；猎物的每日最多被捕食比例仍是 10%。食性仅向相邻营养级变化，生态位保持不变。
- 模拟器每日输出记录环境应用和发生的性状变化。单地块面板不再显示不参与本计算的海拔、水域和生态位输入。

## 验证

| 场景 | 结果 |
| --- | --- |
| 温湿度同升 25 | 第一个 7 天周期只变适温，第二个周期变适湿；有效值分别达到 51.667。 |
| 27 组温差、湿差和植物恢复量组合 | 27 组均存活至第 365 天，存活组的温湿度适应方向均正确，单种群未无故改变运动、体型和食性。 |
| 适宜环境，20 次 2000 天运行 | 性状保持初始值；当前变异决策是确定性的，这 20 次用于检查长时重复运行，不构成随机种子统计。 |
| 无跨营养级关系的单种群长期缺食 | 运动、体型和生育未被缺食单独触发。 |
| 速度和体型关系 | 有持续资源时，较慢捕食者运动 10→12，较小捕食者体型 5→6.667；无持续资源时拒绝运动增加。大体型捕食者在缺食时可从 50 降至 20，确认旧的 30% 限制已移除。 |
| 捕食收益 | 对慢猎物获得 262.5 能量，对快猎物 157.5；较小捕食者获得 181.35，较大捕食者 204.6。 |
| 食性、生育 | 缺少猎物时 1→0；植物竞争下向 1 级积累变异。能量充足但数量下降时生育 50→51，增长且资源受压时 50→49。 |
| 群落列表顺序 | 将竞争种群的列表顺序颠倒后，选出的性状及变化量相同。 |
| 玩家降低植物每日恢复量 | 应用后下一日，体型过大的捕食者从 50 降到 48.096。 |
| 两级、三级食物链 | 各运行 2000 天，配置中的各级保持存活。旧审计程序还重复了 50 次确定性配置，结果一致。 |
| 随机生态边界 | 200 组环境和群落，各运行 365 天，无负数量、非有限资源或越界性状；116 组全群落灭绝，包含无生产者等不可持续配置。 |

`Assembly-CSharp.csproj` 和 `Assembly-CSharp-Editor.csproj` 构建均为 0 警告、0 错误。测试直接调用当前模拟源码和 Unity 基础类型替身；Unity 编辑器中的交互与场景连接仍需手动验收。

## 模型边界

- 当前速度和体型差修正捕食所得净能量，尚未改变每日 10% 的捕食数量上限或逐个猎物的逃脱判定。
- 单一食草种群缺食但没有捕食关系或替代食物时，按本规则会通过人口变化响应，不产生凭空的性状进化。
- 极端温湿度突变仍可能在适应完成前造成灭绝，这是现有适应度与死亡率的结果。
